# ミチナリ（Michinari）

**資格の勉強・読書・仕事。日々の取り組みを記録すると、AIが振り返りとつぎの一歩を返してくれるWindows向けアプリです。**

名前は、カーナビの「道なりに進んでください」に由来します。示された道をたどるだけで目的地にたどり着けること、そして状況が変わればその都度、道が引き直されること。その両方を意味しています。

---

## こんなことに困っていませんか

- 立てた勉強計画が、数日でずれて使い物にならなくなる
- 遅れを取り戻す計画を立て直すのが面倒で、そのまま放置してしまう
- 本を読んでも内容を忘れてしまい、読んだ時間が積み上がった実感がない
- 月末の業務報告や半期の評価シートを前に、「今期なにをしたか」を思い出せない

ミチナリは、こうした「記録し続けること」と「振り返ること」の負担を肩代わりします。

---

## ミチナリでできること

登録する目標には**3つの種類**があり、種類ごとに画面の中身が切り替わります。1つのアプリで、性質の違う取り組みを並行して扱えます。

### 1. 資格試験 — 計画を自動で引き直す

試験日と使う教材を登録すると、**今日やるべき分量**を毎日計算して表示します。

- 進みが遅れても、翌日にそのまま上乗せしません。残りの量と残りの日数から、負荷をならして配り直します
- 「予定より遅れています」と気づいた時点で警告を出し、計画の立て直しを促します
- 勉強しない日（予備日）をあらかじめ決めておけます。決めた休みは「サボり」として扱われません
- 教材を2周・3周と繰り返す使い方にも対応しています
- かけた時間だけでなく、「どれだけ進んだか」「どれくらい理解できたか」を分けて記録できます

試験のあとは合否と得点を登録すると、AIが**なぜその結果になったのか**を、日々の記録をさかのぼって分析します。

### 2. 読書 — 読んだ内容を、自分の資産にする

本を1冊登録し、その日読んだ内容を思い出しながら書き留めます。

- 現在ページの入力は任意です。「今日はここまで読んだ」という短い記録だけでも続けられます（その日に読んだページ数を入力する必要はありません）
- ノルマや達成率のプレッシャーはかけません。書いた内容にAIが応答し、過去の記録とのつながりを示します
- 読み終えたときに、本の要約と「あなたが何を感じ、何に気づいたか」をまとめた**読了レポート**を作れます

### 3. 仕事 — 報告書と評価シートの下書きを作る

案件（プロジェクト）を1件登録し、その日の業務内容を書き留めます。

- 決まった入力欄はありません。文章で書くだけです
- 毎日の記録に対して、AIが努力を言葉にして返します
- 溜まった記録から、**月次報告の下書き**（業務内容の要約／今月の目標／達成度の5段階評価／振り返り／来月の目標案／報告・連絡事項）を作れます
- 同じく**半期評価の下書き**も作れます（3〜8月／9〜翌2月の区切り）
- 生成された内容は、そのまま使わずに**あなたが確認して直せます**。特に達成度の評価は、AIの判断を鵜呑みにしない作りにしています
- 提出フォームへの自動送信は行いません。内容を確認したうえで、あなたの手で転記してください

### すべての種類に共通する機能

| 機能 | できること |
| --- | --- |
| ホーム画面 | 起動すると、今日やること・進み具合・注意すべきことがひと目でわかります |
| カレンダー | 月ごとに、記録した日・予備日・試験日などを色分けして見られます |
| 日々の記録 | その日の実績を記録し、AIと対話しながら振り返れます |
| 分析 | 記録の積み上がりをグラフや一覧で確認できます（表示内容は目標の種類ごとに変わります） |
| 記録の書き出し | 学んだ内容・記録を、読みやすい文書として書き出せます。**他の人に共有するために、個人的な事情を伏せた形で書き出すこともできます** |
| データ管理 | 記録の一括保存・復元ができます |

> AIを使う機能を設定しなくても、記録・閲覧・カレンダー・分析といった基本機能はそのまま使えます。

## 使いはじめる（3ステップ）

1. **ダウンロード**
   [最新版のダウンロードページ](https://github.com/teppei19980914/Michinari/releases/latest) を開き、`Michinari-v◯.◯.◯.zip` をダウンロードします
2. **解凍**
   ダウンロードしたzipファイルを右クリックし、「すべて展開」で好きな場所に解凍します（`Michinari` フォルダができます）
3. **起動**
   `Michinari` フォルダの中の **`Michinari.exe`** をダブルクリックします

数秒でブラウザが自動的に開き、アプリの画面が表示されます。

操作方法は同じフォルダ内の **`ユーザ手順書.pdf`** に記載しています。

<details>
<summary>うまく開かないときは</summary>

- **ブラウザが自動で開かない場合**: ブラウザのアドレス欄に `http://127.0.0.1:8100` と入力してアクセスしてください
- **「WindowsによってPCが保護されました」と表示される場合**: 個人が作成したアプリのため、Windowsが警告を出すことがあります。内容を確認のうえ「詳細情報」→「実行」を選ぶと起動できます
- **黒い画面（コンソール）が一緒に開きます**: これはアプリ本体です。**使っている間は閉じないでください**

</details>

**終了するとき**は、一緒に開いている黒い画面を閉じてください。ブラウザのタブを閉じただけでは終了しません。

## AIの機能を使うには（任意）

日々のフィードバック、計画の見直し提案、合否の要因分析、読了レポート、月次報告・半期評価の下書き。これらのAI機能を使うには、AI基盤「NewtonX」への接続設定が必要です。

1. NewtonXのWeb版で、**アクセストークン**（アプリがあなたの代わりにAIへ接続するための合言葉のようなもの）を発行します
2. ミチナリの「設定」画面を開き、接続先とアクセストークンを入力します

アクセストークンは利用者ごとに個別に発行するもので、配布パッケージには含まれていません。設定しなくても、記録や閲覧などの基本機能はそのまま使えます。

## 安心してお使いいただくために

- **記録はあなたのPCの中だけに保存されます。** 外部のサーバーへ送られることはありません
- **インターネット接続は不要です。** AI機能を使うときだけ通信します
- 動作環境は **Windows** です。ブラウザは Chrome / Edge などの最新版をお使いください

記録は次の場所に保存されます。

```
%LOCALAPPDATA%\Michinari\data\
├── michinari.db     ← 記録の本体
├── backups\         ← 自動バックアップ
└── exports\         ← 書き出したファイルの保存先
```

## 新しいバージョンに入れ替える

1. [最新版のダウンロードページ](https://github.com/teppei19980914/Michinari/releases/latest) から新しいzipをダウンロードして解凍します（各版の変更点は [リリースノート](docs/release-notes/) を参照してください）
2. 古い `Michinari` フォルダを、新しいものに置き換えます
3. `Michinari.exe` をダブルクリックします

**これまでの記録はそのまま引き継がれます。** 記録は上の「保存されます」の場所に置かれており、アプリのフォルダとは別に管理されているためです。内部の構造が変わる更新でも、起動時に自動で移行され、その前にバックアップも自動で作られます。

## アンインストール

1. 解凍した `Michinari` フォルダを削除します
2. 記録も消す場合は `%LOCALAPPDATA%\Michinari` フォルダを削除します

> 記録を消す前に、アプリの「データ管理」画面から書き出しておくことをおすすめします。
