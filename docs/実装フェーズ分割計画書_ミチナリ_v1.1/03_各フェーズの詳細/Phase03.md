### Phase 3：目標・リソースAPI

| 項目 | 内容 |
| --- | --- |
| 目的 | 目標と教材、リソースの登録・編集を可能にする |
| 投入文書 | CLAUDE.md、運用設計ルール、設計書 データ構造編（第6章）、仕様書（第6.2〜6.3節、第7章、第10章） |

**実装対象**

- 目標のCRUDと状態遷移（activate / pause / resume / close）
- 試験科目のCRUD、受験日の確定処理
- 教材のCRUD、科目との紐付け、締切の自動導出、予定周回数の管理
- 周回ごとの進捗取得
- 負荷プロファイルのCRUD
- リソーススロットのCRUD、曜日別既定値、1日の境界時刻
- 配分状況の取得
- リプラン履歴の取得
- バリデーション（仕様書 第10章）

**完了条件**

- リソース配分の合計が100%を超える保存が拒否される
- 一時停止からの復帰時、リソース不足でエラーとなる
- 受験日を確定日に変更すると計画基準値が再設定される
- 教材と科目の紐付け変更で締切が再計算される
- 予定周回数を完了済み周回数未満に変更できない
- 予定周回数の変更で計画基準値が再設定される
- クローズ済み目標への更新が拒否される
