### Phase 6：フロント基盤とダッシュボード

| 項目 | 内容 |
| --- | --- |
| 目的 | フロントエンドの基盤を確立し、ダッシュボードを実装する |
| 投入文書 | CLAUDE.md、運用設計ルール、仕様書（第4〜5章、第6.1節） |

**実装対象**

- Vite + React + TypeScript + Tailwind の構成
- ルーティングとグローバルナビゲーション
- APIクライアントの共通処理（エラーハンドリング、型定義）
- ロケールファイル（ja.json）の構造確立
- 共通コンポーネント（ボタン、入力欄、カード、モーダル、トースト）
- ダッシュボード画面（SC-01）

**完了条件**

- 全UI文言がロケールファイルから供給される
- ダッシュボードが2秒以内に初期表示される
- 今日の一言が非同期で遅れて表示される
- 警告バナーが条件を満たすときのみ表示される
- 本日の判定にサーバから取得した論理日を用いている
- 本日のノルマに現在周回が表示される

**注意点**

- **文字列リテラルをコンポーネントに直接書かない。** ここで規律が崩れると全画面に波及する
- クライアント側でシステム日付から論理日を判断しない
