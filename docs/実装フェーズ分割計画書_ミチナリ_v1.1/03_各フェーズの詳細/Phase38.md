### Phase 38：初学者導線（ウェルカム画面・簡易作成・資格ウィザード）

| 項目 | 内容 |
| --- | --- |
| 目的 | 非エンジニアの初回起動時の脱落を防ぐ。読書・仕事は1画面の簡易作成、資格はテンプレート選択とウィザードで開始できるようにする |
| 投入文書 | CLAUDE.md、docs/CODING_RULES.md、docs/要件定義書_ミチナリ_v1.1.md（6.12節、R-88〜R-92）、docs/仕様書_ミチナリ_v1.1.md（6.1.1〜6.1.2、6.2〜6.3節）、docs/設計書_データ構造編_ミチナリ_v1.1.md（5.3節、6.2節） |

**注記**：コード内には「Phase37」（デスクトップ常駐・記録リマインド通知機能）が既に広く浸透しているが、本計画書側は改訂履歴1.1（改23）時点でPhase36までしか反映されていなかった（ドキュメントの反映漏れ）。番号の重複を避けるため、本開発はPhase38として登録する。

**背景**

初回起動時、目標が1件も無い状態でもダッシュボードが従来どおり表示され、「何をすればいいか分からない」で利用者が止まっていた。特に資格モードは科目・教材・スロット・負荷係数など設定項目が多く、非エンジニアが最初に選ぶには負担が大きい。読書・仕事は書名・案件名だけで始められる非対称性があるため、この非対称性を導線設計に反映した。

**実装対象**

- ウェルカム画面（独立ルート`/welcome`）：目標0件時に`DashboardPage`からリダイレクト。既存ユーザ・開発者が使い方を再確認できるよう、ヘルプ画面からも常時再アクセスできる導線とした（当初案の「DashboardPage埋め込み」から設計変更）
- 読書・仕事の簡易作成（`QuickCreateGoalModal`）：1画面で作成し即座に進行中へ。バックエンド必須項目のうち簡易フォームで問わない項目（総ページ数・読了目標日・想定業務内容）は暫定値を補い、目標詳細画面で後から訂正する前提とした
- 資格モードのテンプレート：`backend/app/templates/exams/`配下にJSON6件（ITパスポート・基本情報・応用情報・情報処理安全確保支援士・ネットワークスペシャリスト・データベーススペシャリスト）を同梱。都度ディレクトリを読み込み、DBへはシードしない
- 資格ウィザード（`ExamGoalWizardPage`、5ステップ）：試験選択→科目・受験日→教材確認→学習時間設定→確認して開始。既存の目標詳細画面は置き換えず、作成経路の追加とした
- 上級設定の折りたたみ：負荷プロファイルタブ、教材の必要連続時間・必要環境・品質指標の方式を既定で折りたたむ（`CollapsibleSection`を新規実装。既存に前例なし）

**完了条件**

- 目標0件で起動するとウェルカム画面が表示される
- 読書・仕事は1画面で作成でき、作成後すぐに記録できる
- 資格はテンプレートを選ぶと科目・教材例が入った状態でウィザードが進み、簡易時間設定からスロットが自動生成される
- テンプレートJSONの編集・追加が選択肢に反映される
- 既存の目標詳細画面からの作成・編集が従来どおり動作する
