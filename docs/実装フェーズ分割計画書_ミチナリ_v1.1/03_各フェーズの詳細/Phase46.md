### Phase 46：記録リマインドの到達性案内

| 項目 | 内容 |
| --- | --- |
| 目的 | 記録リマインドの通知はミチナリが起動している間だけ動作し、Windows起動時の自動起動は既定でオフのため、多くの利用者に通知が一度も届いていない可能性がある。新規利用者には最初の目標作成直後に1問だけ質問し、既存利用者（記録リマインドのみオンで自動起動がオフ）にはダッシュボードで一度だけワンクリック案内を出し、いずれも通知が確実に届く状態へ導く |
| 投入文書 | 開発Todo「リマインド導線」v1.0、要件定義書6.16（R-122〜R-125）、仕様書6.1.4・6.11、設計書 データ構造編 5.2・6.2、CODING_RULES.md |
| 完了条件 | 開発Todoの作業手順（§3）が全てチェック済みであること。バックエンド・フロントエンドのテストが通り、カバレッジが例外処理を除き100%であること |
| 前提の確定 | 表示条件は`GET /dashboard`の2フィールド（`show_reminder_onboarding_prompt`・`show_reminder_autostart_banner`）に一本化し、都度算出する（画面個別のタイミングに依存させない）。自動起動のWindowsレジストリへの即時反映は、設定の保存とは別の専用API（`POST /desktop/autostart/sync`）で行う（従来は常駐起動時にしか反映されなかった既知の制約への対応。既存の設定画面からの保存は変更しない）。表示済み・閉じた済みの2フラグは新規`app_setting`キーとして起動時シードで投入し、Alembicマイグレーションは行わない（既存テーブルへの行追加のみのため） |
