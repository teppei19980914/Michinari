### Phase 51：ふりかえりまとめと社内共有カード

| 項目 | 内容 |
| --- | --- |
| 目的 | ミチナリは一人で完結しており、誰かに見せる・褒められるという動機が働かない。目標を完了したとき、または利用者が期間を指定したとき（年末のまとめ等）に、積み上げを1枚のカードにまとめ、社内チャットへ貼れる画像として保存できるようにする |
| 投入文書 | 開発Todo「まとめと共有カード」v1.0、要件定義書6.21、仕様書3章・6.2・6.10・6.11、設計書 データ構造編5.2・6.API設計、設計書 ロジック・プロンプト編28章、CODING_RULES.md |
| 完了条件 | 開発Todoの作業手順（§3）が全てチェック済みであること。バックエンド・フロントエンドのテストが通り、カバレッジが例外処理を除き100%であること |
| 前提の確定 | 新規テーブルは追加しない（集計・AI一文のいずれも永続化しない。都度算出とフロント状態のみ）。対象は目標完了時（`CLOSED_WITH_RESULT`）と、利用者が目標を1つ選んで期間を指定する場合の2契機。カード項目は記録日数・最長の連続記録日数（新規算出関数）・いちばん多く書いたテーマ（資格試験・読書のみ）・達成した節目・道のりマップ縮小図・AIが選んだ一文（AI設定時のみ）。カードは常に匿名化方式を適用し、AI一文は記録の要約・一般化によって新しく生成する（逐語引用しない）。PNG画像化・クリップボードコピーは新規ライブラリを追加せずSVG→canvas変換で実装する |
