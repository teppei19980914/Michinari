### Phase 52：ひとこと記録モード

| 項目 | 内容 |
| --- | --- |
| 目的 | 気分スタンプ＋1行メモだけで日次記録を確定できる「ひとこと記録モード」を追加する。資格試験・読書・仕事のいずれも、数値実績や質問回答を書く余裕が無い日でも記録を途切れさせずに済むようにする |
| 投入文書 | 開発Todo「ひとこと記録」v1.0、要件定義書6.22、仕様書3章・6.5・6.8・10章、設計書 データ構造編5.2・5.4・6.API設計、設計書 ロジック・プロンプト編17.2.1・17.6.1・17.8.1・29章、CODING_RULES.md |
| 完了条件 | 開発Todoの作業手順（§3）が全てチェック済みであること。バックエンド・フロントエンドのテストが通り、カバレッジが例外処理を除き100%であること |
| 前提の確定 | 気分はカテゴリ単位（goal非依存）の新規1テーブル`daily_record_mood`へ保存する（既存の`daily_goal_diary`・`reading_log`・`work_log`への列追加はしない）。1行メモは専用フィールドを設けず既存の自由記述欄（`diary_learned`／`recall_body`／`body`）へ既存の結合処理で格納する。短文用AIフィードバックは新規`AiPurpose`3種（`DAILY_FEEDBACK_BRIEF`系）を追加し会話・アシスタント設定を通常モードと分離する。「最後に使ったモード」はカテゴリ別に`app_setting`で記憶する。1行メモの最大文字数はフロントエンドの入力欄制約としてのみ使い、サーバ側では強制しない |
