### Phase 53：単語帳（要件A：基盤と問題集）

| 項目 | 内容 |
| --- | --- |
| 目的 | 資格試験の目標に紐づく単語帳（デッキ）・カードを登録し、AIを使わない問題集（カードをめくる・入力式・4択）で理解度を確認できる機能を追加する。既存の「今日の復習」（Phase49）と異なり、日次報告の蓄積に依存せず利用者が明示的に用語を増やせる |
| 投入文書 | 開発Todo_単語帳_v1.0、要件定義書6.23、仕様書6.20・3（機能一覧GOL-23）・4（画面一覧SC-22）、設計書 データ構造編5.1・5.2・5.4・5.6・6（API設計）、設計書 ロジック・プロンプト編30章、CODING_RULES.md |
| 完了条件 | 開発Todoの作業手順（§3.A）が全てチェック済みであること。バックエンド・フロントエンドのテストが通り、カバレッジが例外処理を除き100%であること |
| 前提の確定 | 単語帳は資格試験（EXAM）の目標にのみ作成できる。新規テーブルは`vocab_deck`・`vocab_card`・`vocab_answer_log`の3つ（`create_table`のみ）。目標削除時はCASCADEで連動削除、目標のアーカイブ・中断・完了では削除しない。成績（正答数・誤答数・正答率・連続誤答数・最終解答日）は保存せず`vocab_answer_log`から都度算出する。AIは一切使わない（要件B〜Eで今日の復習統合・AI注入・用語提案・習得可視化を別フェーズとして後続する）。単語帳はナレッジエクスポートの対象外 |
