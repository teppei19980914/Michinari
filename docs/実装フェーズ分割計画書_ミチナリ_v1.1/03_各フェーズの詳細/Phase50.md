### Phase 50：1年前の今日

| 項目 | 内容 |
| --- | --- |
| 目的 | 毎日同じ形の画面だけでは予想外の楽しさがない。過去の同じ日の記録をダッシュボードにときどき表示し、積み上げてきたことを実感できるようにする |
| 投入文書 | 開発Todo「1年前の今日」v1.0、要件定義書6.20、仕様書3章・6.1.7・6.11、設計書 データ構造編5.2・6.2、設計書 ロジック・プロンプト編27章、CODING_RULES.md |
| 完了条件 | 開発Todoの作業手順（§3）が全てチェック済みであること。バックエンド・フロントエンドのテストが通り、カバレッジが例外処理を除き100%であること |
| 前提の確定 | 新規テーブルは追加しない。表示するか否か・どの記録を選ぶかは、サーバーの論理日から`hashlib.sha256`ベースの決定的な値で都度算出し、保存しない（同じ日は常に同じ結果になる）。対象は資格試験の日記・読書の想起記録・仕事の業務記録のうち本文が入力されている記録。削除済み目標の記録は完全削除時のカスケード削除により自動的に対象外、アーカイブ済み・クローズ済みの目標の記録は対象に含める。候補（何か月前か）・表示確率・記録本文の抜粋文字数・表示の有効/無効はいずれも`app_setting`に外部化し設定画面から変更可能。AIは使用せず、`GET /dashboard`へのフィールド追加のみ（新規エンドポイントなし）で完結させ、ダッシュボード初期表示2秒以内の性能要件を守る |
