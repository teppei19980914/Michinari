### Phase 43：ヘルプAIアシスタント

| 項目 | 内容 |
| --- | --- |
| 目的 | ヘルプ本文（`ja.json` の `help`）を根拠に、利用者の質問へチャット形式で答える。ヘルプを能動的に探さなくても必要な情報に届くようにする |
| 投入文書 | 開発Todo「ヘルプAIアシスタント」v1.0、要件定義書 6.13、仕様書 6.18・8.1（AI-14）、設計書 ロジック・プロンプト編 23章・データ構造編 5.2・5.5、CODING_RULES.md、OPERATIONS.md |
| 完了条件 | 開発Todo §8 を満たすこと。バックエンド・フロントエンドのテストが通り、カバレッジが例外処理を除き100%であること。既存DBへのマイグレーション（`ai_forbidden_term` の新設）と配布物への同梱（`help_content.json`）が確認できること。実機検証（開発Todo §6）の結果を記録すること |
| 前提の確定 | 使用アシスタントは GPT-5 mini（高速、ナレッジなし、既存用途で未使用）。質問ごとにチャットを作成し回答後に削除する（1問1答、文脈は引き継がない）。ヘルプ本文の正は `ja.json`（書き出し時に生成） |
| 同時に修正した既存の不具合 | テンプレート変数の展開を1回のパス処理へ（利用者の入力に含まれる `{{...}}` が別の変数として展開される問題）。全利用者入力のプロンプトに影響するため、既存機能の回帰テストを追加 |
