### Phase 47：道のりマップ

| 項目 | 内容 |
| --- | --- |
| 目的 | ミチナリの名前の由来（カーナビの「道なりに進んでください」）どおり、目標ごとの「スタート→現在地→ゴール」を図として可視化し、今どこにいてゴールまであとどれくらいか、計画を引き直しながらゴールへまっすぐ向かい続けられるというミチナリの強みをひと目で分かるようにする |
| 投入文書 | 開発Todo「道のりマップ」v1.0、要件定義書6.17（R-126〜R-131）、仕様書6.1.5・6.2・13.8、設計書 ロジック・プロンプト編25章、設計書 データ構造編6.2、CODING_RULES.md |
| 完了条件 | 開発Todoの作業手順（§3）が全てチェック済みであること。バックエンド・フロントエンドのテストが通り、カバレッジが例外処理を除き100%であること |
| 前提の確定 | 資格試験目標は山（山頂＝全科目の受験を終える日、標高＝全周回を通した進捗率）、読書目標は地図上の道（道の長さ＝総ページ数、現在地＝現在ページ）、仕事目標は現在の評価期間の終わりまでの足跡の積み上げとして描く。新しい値はDBに保存せず、既存テーブルから都度算出する（マイグレーション不要）。ダッシュボードの目標カードには読み取り専用の縮小版（軽量フィールドのみ）、目標詳細画面の新規タブ「道のり」には詳細版（計画線・実績線・足跡・道標・リプラン目印）を表示し、重い算出を初期表示（2秒要件）から分離する。進捗状態アイコン（遅れ／予定どおり／先行）・道の引き直し目印は、既存の設計方針（計画基準値・完了予測は資格試験目標専用）に合わせ資格試験目標にのみ表示する。既知の課題として、予備日アイコン（UI-07）の読書目標への適用が未反映（13.5の既定方針との不整合）であり、後続フェーズで解消する |
