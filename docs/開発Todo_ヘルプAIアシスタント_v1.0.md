## 4. 処理フロー（確定版）

1. 入力検証：空・300字超（`ai.help_question_max_chars`）を拒否。制御文字は除去。
2. 禁止語判定：NFKC 正規化・小文字化・空白除去後に照合。該当は送信せず `unavailable`（記録しない）。
3. ヘルプ本文：全文が予算内なら全文。超過時は質問の語で各セクションを採点し、上位から予算内で選択。該当0件は送信せず `notFound`。
4. 質問ごとに新規チャット（フォルダ `ai.help_folder_name`）を作成（`ensure_conversation`、スコープ `HELP_ASSISTANT`、スコープキーは乱数）。
5. 送信（`send_and_log`）。区切りは乱数（nonce）。質問内の `<` `>` は全角に置換してから埋め込む。
6. 出力検証：末尾の `[出典: ...]` を読み、IDが実在するもののみ採用。0件は `notFound`。禁止語を含む、または上限超過は `unavailable`。
7. 出典行を取り除いて表示。出典名を添える。
8. 後始末：チャットを削除し、一覧で削除を確認。対応する会話行を削除。失敗は記録して回答は返す。
9. 直列化：処理全体をプロセス内ロックで保護（単一端末のため）。

## 5. 禁止語の初期一覧（汎用・運用で追加削除できる）

- 指示の上書き・役割変更を狙う語：「指示を無視」「前の指示」「システムプロンプト」「開発者モード」「制限を解除」「役割を変えて」「ignore previous instructions」「system prompt」
- 攻撃・危険行為の依頼：「爆弾の作り方」「毒の作り方」「ハッキングの方法」
- 差別・侮辱の語：汎用的な侮辱語を数語（固有名詞・個人を指す語は含めない）

※ 語は `ai_forbidden_term` に投入する。コードには書かない。誤検出が多い語は運用で無効化する（`enabled = false`）。
