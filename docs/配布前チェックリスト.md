# 配布前チェックリスト — ミチナリ

本ドキュメントは、非エンジニアを含む利用者への配布可否を判定するための手動確認項目をまとめたものである（配布前改善S-6 6-4）。

対象は「テストスイート・`release.bat`のリリースゲートでは自動的に確認できない項目」に限る。テストで確認できる項目（画面の振る舞い等）は`実装フェーズ分割計画書_ミチナリ_v1.1.md` Phase 35が既に描画テストへ置き換え済みであり、本チェックリストへは転記しない（重複記述の禁止、CLAUDE.md）。

## このチェックリストを使うタイミング

`OPERATIONS.md` 7.4「配布パッケージのビルド」の手順3（`backend/release.bat`実行）の後、GitHub Releasesの下書きを公開する前に実施する。

```
1. 開発（dev/YYYY-MM-DD）
2. main へマージする
3. backend/release.bat を実行する（テスト・リリース前スモーク・パッケージ化・下書きリリース作成まで自動）
4. 本チェックリストを実施する   ← ここ
5. GitHub Releases の下書きを公開する
```

`release.bat`が自動で確認する項目（起動確認・既存DBの移行確認）は本チェックリストへ含めない。詳細は`OPERATIONS.md`「リリース前スモークテスト」を参照。

## 1. AI接続（実機での手動確認、実装フェーズ分割計画書Phase 11由来）

外部サービス（NewtonX ADK）への依存と、利用者ごとに異なるPAT・テナント環境が前提のため自動化していない。配布先の1台（またはテッペイさんの手元の実機）で以下を確認する。

| # | 確認項目 | 確認方法 | 調整先（app_setting） |
| --- | --- | --- | --- |
| 1 | PATによる認証で疎通できること | 設定画面「AI接続」でHost・PATを入力し「接続を確認する」を押す。「接続できました」が表示されること（S-5 5-2により、ボタン押下時に実際にAI基盤と通信して判定するようになった。誤ったPAT・Hostでは「接続できませんでした」が表示されることも確認する） | — |
| 2 | フォールバックのブラウザ認証フローが動作すること | PAT未入力のまま「Personal Access Token」欄を空にして再認証操作を行い、ブラウザが開き認証完了後に「認証済み」へ切り替わること | — |
| 3 | ポート（8100と8400）が衝突しないこと | フォールバック認証使用時、ブラウザ認証用のポート8400が他プロセスと競合していないこと | `server.port` |
| 4 | アシスタント一覧が取得でき、用途ごとに選択できること | 設定画面「AI接続」のアシスタント選択欄に一覧が表示され、保存できること | `ai.assistant_uid.*` |
| 5 | Web検索の無効化が有効に働くこと | AI対話（日次報告フィードバック等）で、検索結果らしき情報が応答に混入しないこと | — |
| 6 | 目標名のフォルダが作成されること | NewtonX Web版側で、目標ごとのフォルダ（`{ai.folder_prefix}_{目標名}`）が作成されていること | `ai.folder_prefix` |
| 7 | 応答時間が妥当であること | AI対話のタイムアウトが頻発しないこと | `ai.timeout_seconds`（既定60秒） |
| 8 | 入力上限が妥当であること | 長文の記録でも送信でき、縮退（要約への置き換え）が過剰に発生しないこと。通信ログで送信文字数と縮退有無を確認する | `ai.max_prompt_chars` |
| 9 | 頻度制限でエラーが出ないこと | 週次要約の連続生成（起動時の遡及生成）でエラーが出ないこと | `ai.min_interval_seconds` |
| 10 | 応答品質が妥当であること | フィードバックが期待した構成・深さを持つこと（負荷を減らす提案の頻度、成長の指摘の具体性、行動提案の実行可能性） | プロンプトテンプレート |
| 11 | 複数往復の対話が成立すること | 同じ日のAI対話で、前の発言を踏まえた応答が返ること（対話履歴の全文注入によって成立する設計。親メッセージ順序機能は使用しない） | — |
| 12 | チャット作成直後の送信・削除が安定していること | 新規チャット作成直後にメッセージ送信・削除を行い、エラーにならないこと | — |

## 2. 配布物そのものの確認

## 3. 利用者向けドキュメントの整合性（S-6 6-5関連）

| # | 確認項目 | 確認方法 |
| --- | --- | --- |
| 16 | ユーザ手順書がUI変更に追随していること | `docs/ユーザ手順書.pptx`・`.pdf`の最終更新日と、直近リリースの変更点（特にAI接続設定の導線・画面キャプチャ）を突き合わせる |
| 17 | ヘルプ画面（SC-14）の説明文言が実装と一致していること | 特にAI接続の説明（「接続を確認する」の挙動等）が実態と乖離していないこと |

**既知の制約（2026-09-20時点、S-6 6-5対応分）**：`docs/ユーザ手順書.pptx`のスライド15（AI接続設定）の本文テキスト（ボタン名「再認証する」→「接続を確認する」、注意書き）はS-5 5-2の実装に合わせて修正済み。ただし同スライドに埋め込まれた画面キャプチャ画像自体（`image10.png`）は旧ボタン名のままであり、実機でのアプリ起動・スクリーンショット再取得が必要（この環境ではAI基盤への実際の接続・PowerPoint/LibreOfficeによるPDF変換ができないため対応できなかった）。`docs/ユーザ手順書.pdf`はpptxからの再エクスポートが必要なため未更新。配布前に、Windows実機でPowerPointから「エクスポート→PDF作成」を行い、`docs/ユーザ手順書.pdf`を更新すること。あわせてスライド15の画面キャプチャも、実際のAI接続設定画面（AiConnectionGuideの4ステップ案内ボックスを含む最新のレイアウト）で撮り直すことが望ましい。
