## 5. 画面遷移

### 5.1 全体構造

```
グローバルナビゲーション
  ├─ ダッシュボード（SC-01）※起動時の初期表示
  ├─ 目標一覧（SC-02）
  ├─ 本棚（SC-18）
  ├─ カレンダー（SC-05）
  ├─ 分析（SC-09）
  ├─ 設定（SC-11）
  └─ ヘルプ（SC-14）
```

### 5.2 遷移関係

```
SC-01 ダッシュボード
  ├─[本日の報告ボタン]──→ SC-06 日次報告
  ├─[警告バナー]────────→ SC-03 目標詳細・編集
  ├─[目標カード]────────→ SC-03 目標詳細・編集
  └─[統計カード]────────→ SC-09 分析

SC-02 目標一覧
  ├─[新規作成]──────────→ SC-03 目標詳細・編集
  ├─[目標選択]──────────→ SC-03 目標詳細・編集
  ├─[結果登録]──────────→ SC-10 受験結果登録
  ├─[クローズ済目標選択]─→ SC-13 ナレッジエクスポート
  ├─[詳細・再開へ]────────→ SC-03 目標詳細・編集（完了・中断の目標も操作欄から再開できる。1.1改41）
  ├─[アーカイブ]─────────→ MD-07（確認後、SC-02内でアーカイブ済み表示に移動）
  ├─[復元]───────────────→ SC-02 内で通常表示に戻る
  └─[完全に削除]─────────→ MD-08（目標名の入力で確定後、SC-02内から削除。1.1改41）

SC-18 本棚
  ├─[書籍を選択]─────────→ SC-19 書籍詳細
  ├─[棚にしまう]─────────→ 確認後、SC-18内でしまった本セクションに移動（アーカイブ操作。SC-02の[アーカイブ]と同じ`archived_at`を用いる）
  ├─[棚に戻す]───────────→ SC-18 内で通常表示に戻る
  └─[完全に削除]─────────→ MD-08（確認後、SC-18内から削除）

SC-19 書籍詳細
  └─[本棚へ戻る]─────────→ SC-18 本棚

SC-03 目標詳細・編集
  └─[リソース設定リンク]─→ SC-04 リソースマスタ設定

SC-05 カレンダー
  ├─[未入力日を選択]────→ SC-06 日次報告 または SC-07 進捗のみ登録
  ├─[進捗のみ登録日を選択]→ SC-06 日次報告（昇格）または SC-08 閲覧
  └─[報告済日を選択]────→ SC-08 日次報告閲覧

SC-06 日次報告
  └─[確定]──────────────→ SC-01 ダッシュボード

SC-08 日次報告閲覧
  └─[コメント追加]──────→ SC-08 内で処理

SC-10 受験結果登録
  └─[クローズ実行]──────→ SC-13 ナレッジエクスポート

SC-11 設定
  ├─[リソースマスタ設定]→ SC-04 リソースマスタ設定
  ├─[データ管理]────────→ SC-12 データ管理
  └─[システム情報]──────→ SC-15 システム情報
```

### 5.3 モーダル

| モーダルID | 表示契機 | 内容 |
| --- | --- | --- |
| MD-01 | 強制リプラン条件の充足 | 乖離状況の提示と目標編集画面への誘導。閉じて続行可能 |
| MD-02 | 受験日の確定操作 | 確定に伴う計画再算出の確認 |
| MD-03 | 目標のクローズ操作 | 読み取り専用への移行の確認 |
| MD-04 | 目標の一時停止解除 | リソース空き不足時のエラー表示 |
| MD-05 | インポート実行 | 既存データの上書きに関する確認 |
| MD-06 | 総括レポート生成中 | AI応答の待機表示 |
| MD-07 | 目標のアーカイブ操作 | 一覧から非表示になる旨の確認。いつでも復元できる旨を併記 |
| MD-08 | アーカイブ済み目標の完全削除操作 | 元に戻せない旨の確認。「学習実績も含めて完全に削除する」チェックボックス（既定ON）を表示し、OFF時は実績が残る教材があると削除全体が失敗する旨を併記 |
