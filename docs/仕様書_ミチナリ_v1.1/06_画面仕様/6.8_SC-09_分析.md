### 6.8 SC-09 分析

対象目標は、日次報告（6.5）・カレンダー（6.4）・ダッシュボード（6.1）と同じ目標タブ（GoalTabBar）で1件選択する（1.1改14）。選択中の目標のカテゴリ（資格試験／読書／仕事）に応じてタブ構成を出し分ける。

目標タブに並べる対象は、他の3画面（着手中の目標に限る）とは異なり、**クローズ済みの目標も含む**（分析は結果が出た後の振り返りにも用いるため）。ただしアーカイブ済みの目標（一覧から非表示にするための状態、R-61）と下書きの目標（実績・記録が1件も存在せずどのタブも空になる）は除外する（1.1改19）。

アーカイブ済みの目標については、画面上部に「アーカイブ済みを表示」トグル（チェックボックス）を設け、利用者が任意で目標タブに含められる（1.1改17）。既定はOFF（非表示）とし、対象となるアーカイブ済みの目標が1件もない場合はトグル自体を表示しない（目標一覧6.15と同じ操作方法）。トグルONで表示された目標のタブには、通常の目標と区別できるようアーカイブ済みである旨を併記する。下書きの目標は本トグルの対象外（ONにしても表示されない）。なお、他の3画面（6.1・6.4・6.5／6.7）は目標タブの対象を着手中（`ACTIVE`）に限定しており、7.1.1の遷移条件により「アーカイブ済みかつ着手中」の目標は存在し得ないため、これらの画面には本トグルを設けない。

**タブ構成（資格試験目標、category=EXAM）**

| タブ | 内容 |
| --- | --- |
| 品質推移 | 教材別の品質指標推移。日別・週別・月別を切替。合格基準線を重畳。周回別に系列を分離 |
| 進捗 | 教材別の累積完了量と計画線の比較。周回の区切りを表示 |

| 実効速度 | 単位時間あたり完了分量の推移。周回別に系列を分離 |
| ガントチャート | 教材の開始日から締切までの帯と、現在の進捗位置 |
| リプラン履歴 | 計画基準の変更履歴。日時、契機、変更前後のノルマ |

**タブ構成（読書目標、category=READING。1.1改14で追加）**

上記7タブのうち品質推移・進捗・完了予測・実効速度・ガントチャート・リプラン履歴の6タブはいずれもMaterial（教材）に依存し、読書目標には適用できない（READING/WORKはexam_subject/material/load_profileを作成しない、6.2参照）。代わりに以下の構成とする。

| タブ | 内容 |
| --- | --- |
| 読書記録 | 日々の想起記録（recall_body、任意でページ進捗）を新しい順に列挙 |
| 成長記述 | AIによる過去記述との比較結果の履歴（選択中の目標宛て分。1.1改15参照） |

| タブ | 内容 |

**成長記述タブについて（1.1改15で改訂）**：日次フィードバックのAI対話を目標単位の会話へ分離したこと（6.5、未決事項L-07の解消方針転換）に伴い、選択中の目標宛ての応答のみを表示する方式に変更した。目標単位分離より前に生成された応答（chat_message.goal_id=NULL、レガシー）は、選択中の目標と同じカテゴリであれば「未割り当て」として併せて表示し、利用者が記憶を頼りにプルダウンから目標を手動で割り当てられる（同じカテゴリの目標にのみ割り当て可能）。割り当てはデータの更新のみで、AI応答の再生成は行わない。
