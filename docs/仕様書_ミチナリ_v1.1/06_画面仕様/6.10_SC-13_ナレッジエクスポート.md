### 6.10 SC-13 ナレッジエクスポート

**表示要素**

| 領域 | 内容 |
| --- | --- |
| 総括レポート | AIが生成した合否要因分析。未生成の場合は生成ボタンを表示 |
| 学習サマリ | 総投下時間、学習日数、報告率、リプラン回数、最終到達品質 |
| 出力項目選択 | エクスポートに含める項目のチェックボックス |
| 匿名化オプション | 個人を特定する情報の除外設定 |
| プレビュー | 出力内容の確認 |

**出力項目選択**

| 項目 | 既定 | 備考 |
| --- | --- | --- |
| 目標概要 | 含む | 試験名、受験日、学習期間 |
| 教材構成 | 含む | 総量、予定周回、実績周回 |
| 学習量サマリ | 含む | 総投下時間、学習日数、平均時間 |
| 実績推移 | 含む | 日別の投下時間と完了分量 |
| 品質指標推移 | 含む | 周回別の推移 |
| リプラン履歴 | 含む | 変更日時、契機、変更前後 |
| 週次要約 | 含む | 全週分 |
| 振り返りテーマ | 含む（資格試験・読書の目標のみ表示） | テーマ本文と紐付く報告。仕事の目標では表示しない |
| 日記本文 | 含まない | 業務・家庭の情報を含むため既定で除外 |
| AI対話履歴 | 含まない | 分量が大きいため既定で除外 |
| 受験結果 | 含む | 合否、得点 |
| 総括レポート | 含む | — |

**匿名化オプション**

有効にすると、以下を除外または置換する。

| 対象 | 処理 |
| --- | --- |
| 日記本文 | 全面的に除外 |
| 振り返りテーマ | 全面的に除外 | テーマ本文は日記・想起記録から作られるため、日記本文と同様に除外 |
| 週次要約 | 業務・家庭に関する記述を除外するようAIに指示して再生成 |
| 総括レポート | 個人的事情への言及を避けるようAIに指示して再生成 |

**出力形式**

| 形式 | 用途 |
| --- | --- |
| Markdown | 人が読む。他者への共有、振り返り |
| JSON | 機械可読。将来の集計、他アプリへの取り込み |

**読書目標（category=READING）の場合**

対象目標の選択肢に読書目標も表示する（EXP-01）。表示要素・出力項目は以下のとおり読み替える（CLS-07、R-67、R-68）。

| 領域 | 内容 |
| --- | --- |
| 読了レポート | AIが生成した要約と感じたこと・考えたこと・気づいたこと。未生成の場合は生成ボタンを表示 |
| 読書サマリ | 記録日数、連続記録日数、開始日から読了日までの期間 |

出力項目選択のうち「教材構成」「品質指標推移」「受験結果」「合格基準線」に相当する項目は表示しない（該当データを持たないため）。「実績推移」は日別の想起記録一覧、「週次要約」は対象外（15章参照）、「総括レポート」は「読了レポート」と読み替える。匿名化オプションは資格試験と同様に日記相当（想起記録）を除外し、読了レポートを個人的事情への言及を避けるようAIに指示して再生成する。

両形式を同時に出力する。

**仕事目標（category=WORK）の場合**

対象目標の選択肢に仕事目標も表示する（EXP-01）。表示要素・出力項目は以下のとおり読み替える（CLS-09〜12、R-78、R-79、R-81）。

| 領域 | 内容 |
| --- | --- |
| 月次報告・半期評価 | AIが生成した月次報告・半期評価の一覧（期間の新しい順）。各期間について未生成の場合は生成ボタンを表示 |
| 業務サマリ | 記録日数、連続記録日数、着手日からの経過日数 |

出力項目選択のうち「教材構成」「品質指標推移」「受験結果」「合格基準線」に相当する項目は表示しない（該当データを持たないため）。「実績推移」は日別の業務記録一覧、「週次要約」は対象外（読書と同じ理由。15章参照）、「総括レポート」は「月次報告・半期評価」と読み替え、対象goalに紐づく生成済みの全期間分をエクスポート対象に含める（読書の読了レポートと異なり単一のレポートではない点に注意。R-81「既存のナレッジエクスポート機能の対象に含まれる」に対応するための読み替え）。匿名化オプションは資格試験と同様に日記相当（業務記録）を除外し、月次報告・半期評価の各期間分を個人的事情への言及を避けるようAIに指示して再生成する。

両形式を同時に出力する。

**操作**

- 総括レポートの生成および再生成
- 出力項目の選択
- プレビュー表示
- ファイルの出力
