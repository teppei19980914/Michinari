**言語設定の反映範囲（日英i18n対応、2026-10改54）**

「表示｜言語」は画面文言・NewtonXフィードバック・システムトレイ/デスクトップ通知の全てに反映される。言語を変更して保存すると、画面全体を再読み込みして反映する（他の設定項目と異なり即時反映ではない）。既存の記録・過去のAI生成フィードバックは翻訳されず、変更後に新規生成される分のみ変更後の言語になる。

**AI接続手順の段階的な案内（非エンジニア向けエラー表示改善、2026-09-19）**

AI接続の項目は、以下の手順を段階的に表示する。①NewtonX のWeb版を開く（接続先URLが入力済みの場合はリンクを表示）②アクセストークンを発行する（発行画面の場所を文章とスクリーンショットで説明。画像は差し替え可能なダミーを配置）③発行されたトークンを貼り付ける④「接続を確認する」。あわせて「アクセストークンとは、あなたの代わりにアプリがAIへ接続するための合言葉です。他の人に教えないでください」という平易な説明を添える。

SC-04 リソースマスタ設定への遷移リンクを設ける。初期状態のリソース未設定に起因する教材タブでの警告（6.2「教材の必要連続時間・必要環境を満たすスロットが存在しない場合、警告を表示する」）をアプリ利用開始前に防げるよう、SC-03の目標詳細・編集画面（リソース配分タブ）を経由せずとも到達できるようにする。

**デスクトップ常駐と記録リマインド**

本アプリはWindowsの通知領域（システムトレイ）に常駐する。起動してもコンソール画面は表示しない。

| 操作 | 動作 |
| --- | --- |
| アイコンのクリック | ブラウザで画面を開く |
| アイコンの右クリック →「ミチナリを開く」 | 同上 |
| アイコンの右クリック →「終了」 | 処理中のリクエストの完了を待ってからアプリを終了する |

記録リマインドは、設定した時刻にその日の記録が未入力である場合のみ通知する。判定にはシステム
日付ではなく論理的な本日（3.1の1日の境界時刻を考慮した日付）を用いる。

| その日の状態 | 通知 |
| --- | --- |
| 記録済み（進捗のみ登録済み・報告済みのいずれか） | 通知しない |
| 日種別が除外日（OFF） | 通知しない |
| 日種別が予備日（BUFFER） | 通知する（休みの日向けの文面に変える） |
| 上記以外（計画日）で未記録 | 通知する |

通知をクリックすると、その日の日次報告画面（SC-06）をブラウザで開く。通知はアプリの起動中
のみ動作し、常駐プロセスを別に設けない。設定時刻にアプリが起動していなかった場合、その日の
通知は行わない。

「Windows 起動時に自動で起動する」を有効にすると、サインイン時にアプリが通知領域で待機する。
既定は無効とする（利用者の端末設定へ手を入れるため、明示的な有効化を求める）。

**自動起動の即時反映（1.1改61、開発Todo「リマインド導線」v1.0）**：この画面からの保存は、
値を保存するのみで、Windowsレジストリへの実際の反映は次回の常駐起動時まで行われない
（従来からの制約）。一方、ダッシュボードの2つの到達性案内（6.1.4）から自動起動を有効化
する場合は、保存に続けて専用API（`POST /desktop/autostart/sync`）を呼び、その場でレジストリ
へ反映する。開発環境（パッケージ化していない状態）では反映自体を行わず、その旨を示す。
反映できなかった場合は利用者にわかる形で知らせる。
