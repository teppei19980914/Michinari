### 6.19 SC-21 添付ファイル管理（開発Todo「添付ファイル機能」v1.0）

資格試験の過去問・解答例・採点講評、ユーザー自身の記述式回答、仕事の関連ドキュメント等のPDFを登録し、一覧・削除を行う画面。目標一覧（SC-02）の近くに導線を置く（R-118）。goal非依存の共通プールであり、本画面で登録したファイルはどの目標の日次報告（SC-06）・目標相談タブ（SC-03）からも選択できる。

**表示要素**

| 領域 | 内容 |
| --- | --- |
| 添付ファイル一覧 | 登録順（登録時に割り振られる連番）で、ファイル名・抽出文字数を表示する |
| 空状態 | 1件も登録されていない場合は案内文を表示する |
| 上限の案内 | 保持できる件数の上限（`app_setting`、既定50件）に達している場合、アップロードボタンを無効化し、上限に達している旨を表示する |

**操作**

- 「PDFを追加」ボタン：ファイル選択ダイアログ（`.pdf`のみ）を開く。選択すると即時にアップロードし、アプリがテキストを抽出して登録する（R-115）。アップロード中はボタンを無効化する
- 各行の「削除」ボタン：確認（共通の削除確認）のうえ1件削除する。削除は常に行える。過去の対話・質問でこのファイルが選択されていた場合、「どのファイルを参照したか」の情報のみ失われ、その対話・質問の本文・回答は残る（R-118）

**登録時の検証（サーバ側）**

| 検証項目 | 内容 |
| --- | --- |
| 形式 | PDFのみ（MVP、R-121） |
| ファイルサイズ | `app_setting`の上限（既定20MB）を超えるものは拒否 |
| 抽出文字数（下限） | 画像のみのページ等でテキストを抽出できない（既定50字未満）場合は拒否し、エラーメッセージを表示する |
| 抽出文字数（上限） | `app_setting`の上限（既定20,000字）を超える場合は拒否 |
| 禁止語 | 抽出したテキストに禁止語（目標相談チャット・ヘルプと共有する禁止語リスト）が含まれる場合は拒否 |

いずれの検証に失敗した場合も、ファイルは一切保存しない。

**保存するデータ**

PDF原本は保存せず、抽出したテキストのみを保存する（データ量を抑える設計、R-115）。
