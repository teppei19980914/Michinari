### 6.14 SC-15 システム情報

SC-11 設定から遷移する、動作中のアプリのバージョン・使用ライブラリを確認するための参照画面
（サポート対応時に配布先のバージョンを確認する用途を想定。データを変更するAPIの書き込みは
持たない。診断ログのエクスポートは読み取りのみで、データベースの内容には触れない）。

| 項目 | 内容 |
| --- | --- |
| アプリバージョン | `backend/pyproject.toml`の`[project].version`（配布パッケージ全体で単一の情報源） |
| ビルド日時 | 配布パッケージのビルド時刻（ソースから起動する開発環境では「開発環境で実行中」と表示） |
| Pythonバージョン | 実行中のPythonインタプリタのバージョン |
| バックエンドライブラリ一覧 | `backend/pyproject.toml`の直接依存の名前と実際にインストールされているバージョン |
| フロントエンドライブラリ一覧 | `frontend/package.json`の直接依存の名前と、`frontend/package-lock.json`で解決された実際のインストール済みバージョン |
| 診断ログの取得（Phase40） | エラーが起きた際に利用者自身が期間を指定して診断ログ（`michinari.log`、下記参照）をダウンロードし、サポートへ共有できる。期間はプリセット（当日／過去3日／過去7日）またはカレンダーでの手動指定から選ぶ。ここでいう「診断ログ」は設定画面（SC-11）の「AI通信ログの保存」（AIとの通信内容を`ai_log`テーブルへ保存する設定、6.11参照）とは別物であり、アプリの動作記録（アクセスログ・エラー・フロントの未処理例外）を指す |

配布・公開手順そのもの（OPERATIONS.md記載）はエンドユーザー向けの内容ではないため対象外とする。
