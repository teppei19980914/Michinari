## 11. 非機能仕様

| 項目 | 仕様 |
| --- | --- |
| 対応ブラウザ | 主要モダンブラウザの最新版 |
| 起動ポート | 8400番以外。既定値は8100 |
| 画面幅 | デスクトップ幅を主対象とする。狭幅時のレイアウト崩れは許容する |
| 応答性能 | ダッシュボード初期表示2秒以内。AI応答は10秒以内を目標とし、超過時は待機表示を継続する |
| 同時実行 | 単一利用者を前提とし、排他制御は行わない |
| 文言管理 | 全UI文言をロケールファイルに外部化する |
| パラメータ管理 | 全パラメータを設定として外部化し、画面から変更可能とする |
| ログ | AI通信の送信内容と応答をローカルに保存する。保持期間を設定可能とする |
| 耐障害性 | AI基盤が利用できない状態でも、実績記録と閲覧が可能であること |
