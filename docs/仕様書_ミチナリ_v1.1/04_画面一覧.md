## 4. 画面一覧

| 画面ID | 画面名 | 概要 |
| --- | --- | --- |
| SC-01 | ダッシュボード | 起動時の初期表示画面 |
| SC-02 | 目標一覧 | 全目標の一覧 |
| SC-03 | 目標詳細・編集 | 目標、試験科目、教材、配分、負荷プロファイルの設定 |
| SC-04 | リソースマスタ設定 | 時間スロット、日種別既定値、1日の境界時刻の設定 |
| SC-05 | カレンダー | 月次表示と日種別指定 |
| SC-06 | 日次報告 | 実績入力、日記記述、AI対話 |
| SC-07 | 進捗のみ登録 | 実績数値のみの入力 |
| SC-08 | 日次報告閲覧 | 過去の報告と対話履歴、コメント |
| SC-09 | 分析 | 各種グラフとガントチャート |
| SC-10 | 受験結果登録 | 科目別の結果入力 |
| SC-11 | 設定 | 各種設定項目 |
| SC-12 | データ管理 | エクスポート、インポート、バックアップ |
| SC-13 | ナレッジエクスポート | 総括レポートの確認と学習記録の出力 |
| SC-14 | ヘルプ | アプリの使い方を集約した参照画面（全画面・全設定項目・プロンプトのプレースホルダー一覧・よくある質問） |
| SC-20 | ヘルプに質問する | 全画面から開くドロワー。質問を送信し、ヘルプ本文に基づく回答・出典・固定文言を表示する（6.18） |
| SC-15 | システム情報 | アプリバージョン・ビルド日時・主要ライブラリ構成の確認 |
| SC-16 | ウェルカム画面 | 目標0件時にSC-01の代わりに表示する初回導線。読書・仕事・資格の3択カード（1.1改29） |
| SC-17 | 資格モード作成ウィザード | テンプレート選択→科目・受験日→教材確認→学習時間設定→確認の5ステップ。SC-03を置き換えない追加の作成経路（1.1改29） |
| SC-18 | 本棚 | 読了・中断した読書目標を書籍カードとして表示する。SC-02のクローズ済み表示を置き換えるものではなく、読書目標専用の追加の入口（1.1改38） |
| SC-19 | 書籍詳細 | SC-18で選んだ1冊について、書誌情報・想起記録・成長記述・振り返りレポートをタブで閲覧する閲覧専用画面（1.1改38） |
| SC-21 | 添付ファイル管理 | PDFの登録・一覧・削除。goal非依存の共通プールで、SC-02の近くに配置する（開発Todo「添付ファイル機能」v1.0） |
