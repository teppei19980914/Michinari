# Michinari v1.17.0 リリースノート

**ダウンロード**: 下の Assets から `Michinari-v1.17.0.zip` → [インストールと使いかた](https://github.com/teppei19980914/Michinari/blob/main/README.md)

## このバージョンの変更

- **総括レポート・読了レポートは、完了した目標で「生成する」を押したときだけ作られます。** 完了の操作では自動で作らなくなりました。完了後は出力画面へ移ります。資格試験も読書と同じ扱いです。
- **実行中・一時停止・中断の目標では、総括レポート・読了レポートは作れません。** 生成ボタンは表示されず、完了後に生成できることを案内します。
- **匿名化してエクスポートするとき、完了していない目標では匿名化版のレポートを作りません**（AI は呼び出しません）。
- **目標の状態を変える操作が失敗したとき、操作名を見出しにしてエラーを表示します**（開始・一時停止・再開・完了・中断・アーカイブ・復元・削除）。ほかの画面にも今後順次広げます。
- 操作ヘルプと説明文を、完了・中断・削除の新しい操作に合わせて更新しました。

## アップデート時のご注意

- **データの移行は不要です。** これまでに入力した内容はそのまま引き継がれます。
- すでに作成済みの総括レポート・読了レポートは、そのまま残ります。
- 完了した目標でまだレポートを作っていない場合は、ナレッジエクスポート画面の「生成する」から作成してください。完了の操作では自動で作られません。
