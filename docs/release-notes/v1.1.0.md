# Michinari v1.1.0 リリースノート

公開日: 2026-09-11
前バージョン: v1.0.0（2026-08-30 公開）

<!-- summary:start -->
資格試験に加えて **読書** と **仕事** の目標を扱えるようになりました。学習時間の配分は「%」から「時間枠ごとの分」に変わります。

**主な変更**
- 読書目標: 毎日の読書記録と、読了時のAIレポート生成
- 仕事目標: 日々の業務記録と、月次報告・半期評価のドラフト生成
- リソース配分を % → 分 に変更（読書も配分対象に）
- 目標のアーカイブ／完全削除
- 複数目標を目標タブで切り替え表示、AI対話も目標ごとに分離

⚠️ **v1.1.0 より前に出力したバックアップJSONは取り込めません。** 更新の前後でバックアップを取り直してください（学習データ自体は自動で移行されます）。

## このバージョンの概要

v1.0.0 は「資格試験の学習計画」専用のアプリでした。
v1.1.0 では **扱える目標の種類が3つに増え**、**学習時間の配分方法が実態に合う形に変わりました**。

| | v1.0.0 | v1.1.0 |
| --- | --- | --- |
| 登録できる目標 | 資格試験のみ | 資格試験・**読書**・**仕事** |
| 学習時間の配分 | 目標ごとに「全体の何%」 | 時間枠ごとに「何分」 |
| 複数目標の同時進行 | 1画面に全目標が混在 | 目標タブで1件ずつ切り替え |
| 目標の整理 | 削除のみ | **アーカイブ**（一覧から退避）・完全削除 |

## 1. 新機能：読書の記録（新しい目標種別）

読んだ内容を毎日記録し、読み終わったときに **AIが「読了レポート」を作成** します。

- 書名・著者・総ページ数・読了目標日を登録
- 毎日「今日読んだ内容」を自由に書き留める（ページ数の入力は任意）
- AIが読書向けの言葉でフィードバック（ノルマ達成を急かす言い方はしません）
- 読み終わったら、本の要約と自分が感じたこと・気づいたことをまとめたレポートを自動生成（納得いかなければ作り直せます）
- ダッシュボードに残日数・直近の記録日・連続記録日数を表示

**資格試験との違い**: 読書には「1日○ページ読まないと間に合わない」というノルマ計算がありません。記録を積み上げ、読了時に資産として活かすことが目的です。

## 2. 新機能：仕事の記録と月次報告（新しい目標種別）

案件ごとに日々の業務を記録し、**会社へ提出する月次報告・半期評価の下書きをAIが作成** します。

- 案件名・想定業務内容・着手日を登録
- 毎日の業務内容を自由に記録
- **月次報告ドラフト**（前月分）: 業務内容の要約／対象月の目標／達成度（5段階）／振り返り／来月の目標案／報告連絡事項 の6項目を生成
- **半期評価レポート**: 3月〜8月・9月〜翌2月の区切りで同様に生成
- 生成後に画面上で修正でき、Markdown形式でダウンロード可能
- ダッシュボードに着手日からの経過日数・直近の記録日・連続記録日数・直近の月次報告の有無を表示

**ご注意**: 外部フォーム（Microsoft Forms 等）への自動送信は行いません。生成された下書きを手で転記してお使いください。

## 3. 変更：学習時間の配分が「%」から「分」になりました

v1.1.0 で最も大きな変更点です。

**これまで（v1.0.0）**
> 「簿記2級に 60%、応用情報に 40%」のように、全体に対する割合で指定

**これから（v1.1.0）**
> 「通勤（7:00-8:00）のうち 30分 は簿記2級」「夜（20:00-22:00）のうち 90分 は簿記2級」のように、**時間枠ごとに実際の分数** で指定

### なぜ変わったのか

- %では「どの時間枠から時間を取るのか」が曖昧でした。朝の通勤（スマホ向け）と夜の机上作業は性質が違うのに、一律の割合で配分されていました
- 分で指定すると「通勤中は単語帳、夜は過去問」という使い分けをそのまま表現できます

### あわせて良くなった点

- **読書も時間配分の対象になりました**。読書も資格勉強も「自由な時間に行うこと」なので、同じ時間枠を取り合う前提に変えました（仕事は勤務時間中のため対象外です）
- 読書の時間配分は **任意** です。設定しなくても読書目標は開始できます
- **まとまった時間が必要な教材の判定が正確になりました**。これまでは「2時間の枠がある」だけで割り当てていましたが、実際にその枠から30分しか確保していなければ90分の作業はできません。配分した分数と比べるよう修正しました
- 時間枠を短くしたり削除しても **保存は通ります**。配分が足りなくなった場合は警告が出るだけなので、「通勤時間が変わった」といった生活の変化を先に登録できます。**過去の記録も消えません**

### 日次報告の入力が変わります

教材ごとに「投下時間 ○分」を1つ入力する形から、**時間枠ごとに分を入力** する形になりました。

- 設定した配分が **初期値として入っている** ので、予定どおりなら入力は不要です
- その日だけ違った場合は書き換えられます（**設定そのものは変わりません**）
- 予定外の空き時間に勉強した場合は「他の時間枠を追加」で記録できます
- すべての欄を空欄にすると「時間未入力」として扱われます（この日は学習ペースの計算から除外されます）

### 時間の表示ルール

分を時間に換算して表示する箇所は、**小数第2位以下を切り捨て** ます（例: 50分 → 0.8時間）。四捨五入はしません。

## 4. 新機能：目標のアーカイブと完全削除

使わなくなった目標を削除せずに **一覧から退避** できるようになりました。

- 進行中でない目標（下書き・一時停止・クローズ済み）をアーカイブでき、いつでも復元できます
- アーカイブ済みの目標は完全削除もできます。削除時に「学習実績も一緒に消すか」を選べます
- 同じ日に他の目標の記録が残っている場合、その日次報告は削除されず保持されます
- 分析画面には「アーカイブ済みを表示」の切り替えを追加しました（初期状態は非表示）

## 5. 改善：複数の目標を同時に進めたときの見やすさ

同時に2件以上の目標を進めている場合、これまでは1つの画面に全目標の情報が並んでいました。
v1.1.0 では **画面上部のタブで目標を1件ずつ選んで表示** します。

対象画面: 日次報告・ダッシュボード・カレンダー・分析・日次報告閲覧

## 6. 改善：AIとの対話が目標ごとに分かれました

これまでは同じ種類の目標が2件あると、AIとの会話が1本にまとまっていました。
v1.1.0 では **目標ごとに独立した会話** になります。

- 「簿記2級」のAI対話に「応用情報」の話題が混ざらなくなりました
- 分析画面の「成長記述」も、選んだ目標宛ての応答だけが表示されます
- 以前の（どの目標宛てか特定できない）応答は「未割り当て」として表示され、あとから手動で目標を割り当てられます

## 7. 改善：日次報告の確定が種類ごとに独立しました

これまでは1日分の報告を確定すると、同じ日の他の種類（読書・仕事）も入力できなくなっていました。
v1.1.0 では **資格試験・読書・仕事をそれぞれ独立して確定** できます。

## アップデート時のご注意

1. **データは自動で移行されます。** 既存の配分（%）は「割合 × 各時間枠の長さ」で分に換算されます。過去の学習記録もそのまま引き継がれます
2. **時間枠を1つも登録していない状態で更新した場合**、換算先がないため配分は空になります。更新後にリソース配分を再設定してください（対象の目標は更新時のログに出力されます）
3. **v1.1.0 より前に出力したバックアップJSONは取り込めません。** データ構造が変わったためです。更新の前後でバックアップを取り直してください
