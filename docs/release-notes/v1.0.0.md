**ミチナリ** の最初の公開版です。資格試験の合格に向けて、学習計画の立案・実行・修正を継続的に支援します。

実績に応じて **日々のノルマを毎日その都度自動で再計算** するのが中核の仕組みです。未達分をそのまま翌日へ積み上げず、残量と残り日数から負荷を平準化して配分し直します。

**主な機能**
- 目標・試験科目・教材の登録（周回数を含めた総作業量の管理）

- 日次報告（実績・日記・AI対話）、ダッシュボード、カレンダー

- 受験結果の登録と、AIによる総括レポート（合否要因分析）
- ナレッジエクスポート、全データのバックアップ

**動作環境**: Windows PC。インターネット接続は不要です（AI連携を使う場合のみ通信します）。学習データは端末内にのみ保存されます。

## このバージョンの概要

**ミチナリ（Michinari）** の最初の公開版です。資格試験の合格を目的に、学習計画の
**立案・実行・修正** を継続的に支援します。

名称はカーナビの案内表現「道なりに進んでください」に由来します。示された道をたどるだけで
目的地（合格）に到達できること、状況に応じて道が引き直されることの両方を意味しています。

ミチナリは学習計画を一度きりの静的な文書として扱いません。実際の学習実績に応じて、
**日々の目標（ノルマ）をその都度自動で再計算し続ける「適応型リプランニング・エンジン」** です。

- 未達分をそのまま翌日に積み上げず、残量と残り日数から負荷を平準化して再配分します
- 学習しない日を決めても罰にはならず、その日に学習すれば以降の負荷が軽くなります
- 「時間をかけたか」だけでなく「どれだけ進んだか」「理解の質」を分けて記録します
- AIとの対話による日次フィードバック、計画修正の提案、受験後の合否要因分析を受けられます

## 1. 目標・試験科目・教材の登録

- 試験名・開始日を登録し、**試験科目** を1件以上ぶら下げます。科目ごとに受験日（確定日／期間指定）を設定できます
- 期間指定の受験日は、日程が決まった時点で **確定日に変更** でき、計画が再算出されます
- 合格基準点は **百分率／点数（何点中何点）** のどちらの方式でも入力できます
- 教材には単位・総量・**予定周回数**・必要連続時間・必要環境・品質指標方式を登録します
- 教材の締切は、紐づく科目の **最早受験日から自動導出** されます（手動での上書きも可能）
- 任意期間に **負荷係数**（負荷プロファイル）を設定でき、繁忙期は軽く、直前期は重くといった調整ができます

## 2. 学習リソース（使える時間）の登録

- **時間スロット**（名称・開始／終了時刻・環境タグ）を登録し、曜日ごとに有効なスロットを割り当てます
- 曜日ごとに **計画日／バッファ日** の既定値を設定でき、祝日一覧の取り込みにも対応します
- 目標ごとの **リソース配分**（全体に対する割合）を指定します。合計が100%を超える設定は保存できません
- **1日の境界時刻** を設定できます。深夜まで学習する習慣がある場合でも、午前1時の学習が翌日分として
  計上されることを防げます（論理日の判断はサーバ側に一元化しています）

## 3. 日次ノルマの自動再計算（本アプリの中核）

その日にこなすべき分量・時間を、**毎日その都度算出** します。

- 残量（総作業量 − 完了量）を、残りの **計画日** と負荷係数で按分します
- **総作業量は周回数を含めて計算** します。「850問を3周」なら総作業量は2550問で、1周目の完了は
  通過点として扱われ、ノルマが消滅しません
- **バッファ日** はノルマ0・分母からも除外されます。バッファ日に学習すれば、その実績は翌日以降の
  ノルマを引き下げる形で即座に報われ、学習しなくても負債は発生しません
- **除外日** は「学習が不可能と事前に分かっていた日」として、速度の算出対象からも外れます
- 教材ごとの **必要連続時間・必要環境** を満たすスロットがあるかを検証し、足りなければ警告します

## 4. 日次報告と記録

| 機能 | 内容 |
| --- | --- |
| 実績入力 | 教材単位で投下時間・完了分量・周回・品質指標を入力 |
| 日記 | その日の行動・所感・学んだ内容を自由記述 |
| AI対話 | 実績と日記を入力にAIからフィードバックを受領 |
| 報告確定 | 確定すると内容は変更不可になります |
| 進捗のみ登録 | 日記もAI対話も行わず数値だけ登録（時間入力は任意） |
| 遡及入力 | 前日までの日付にも入力できます |
| 報告への昇格 | 進捗のみ登録した日を、後から日次報告に格上げできます |
| 報告閲覧・コメント | 過去の報告と対話履歴を閲覧し、コメントを追加・修正・削除できます |

## 5. AI連携（任意）

AI基盤（NewtonX ADK）へ接続すると、以下が利用できます。**接続しなくても記録・閲覧・カレンダー等の
基本機能はすべて使えます。**

- **日次フィードバック** — 実績と日記に対する対話形式の応答
- **リプラン提案** — 計画の修正案の受領
- **週次要約** — 前週分の報告内容の要約
- **今日の一言** — 進捗を踏まえた肯定的な短文（同日中は同じ内容を再表示）
- **成長記述の比較** — 過去の記述との比較結果を分析画面に表示
- **総括レポート** — 受験結果を踏まえた合否要因分析（納得いかなければ再生成できます）

接続は **Personal Access Token（PAT）** で行います。PATは端末ごとに個人で設定する必要があり、
配布パッケージには含まれていません。入力量が多い場合はプロンプトを段階的に縮退して送信し、
縮退が発生した場合は対話領域に表示します。定型プロンプトは設定画面で閲覧・編集・初期値復帰できます。

## 6. ダッシュボードとカレンダー

- 起動時のダッシュボードで、**本日のノルマ・進捗状況・警告** をひと目で確認できます
- 進捗率・連続報告日数・バッファ消費率などの統計サマリを表示します
- 月次カレンダーで **日種別（計画日／バッファ日／除外日）と記録状態** を色分け表示し、特定日の
  日種別を個別に変更できます。各科目の受験日・受験期間もカレンダー上に表示されます
- 日付を選ぶと、その日の日次報告の登録または閲覧へ遷移します

## 7. 分析・可視化

- **品質指標の推移グラフ**（日別／週別／月別の切替）と **合格基準線** の重畳表示
- 教材の **周回ごと** に区別した品質指標の表示
- **ガントチャート** による教材の期間と進捗の表示
- **完了予測日** と締切の乖離、**実効速度**（単位時間あたり完了分量）の周回別推移
- **リプラン履歴** — 計画基準の変更履歴を時系列で表示

## 8. 受験結果の登録と完了処理

- 科目ごとの合否・得点・評価を登録します
- 結果を登録すると目標は **クローズ**（読み取り専用）へ移行します
- AIによる **総括レポート（合否要因分析）** を生成・再生成できます

## 9. ナレッジエクスポート

学習の記録を、次の挑戦や他者への共有のために取り出せます。

- 目標単位で、**人間可読形式／機械可読形式** を選んで出力
- 含める項目を選択でき、**匿名化**（個人を特定する情報の除外）にも対応
- 出力前にプレビューで内容を確認できます

## 10. 設定・データ管理・ヘルプ

- **設定** — AI接続・認証管理・閾値（警告倍率／強制リプラン超過日数）・表示設定・プロンプト管理・
  通信ログの保存有無と保持期間・AI稼働状況の確認
- **データ管理** — 全データのエクスポート／インポート／バックアップ
- **ヘルプ** — 全画面・全設定項目・プロンプトのプレースホルダー一覧・よくある質問を集約
- **システム情報** — アプリバージョン・ビルド日時・主要ライブラリ構成の確認

## 11. 警告・通知

| 条件 | 表示 | 動作 |
| --- | --- | --- |
| 日次ノルマが初期ノルマの警告倍率以上 | ダッシュボードのバナー | 表示のみ。学習は続行可能 |
| 完了予測日が締切を既定日数以上超過 | モーダル | 目標編集画面への遷移を促す。閉じて続行可能 |
| 教材の要求条件を満たすスロットが無い | 目標編集画面の警告 | 保存は許容 |
| リソース配分の合計が100%超過 | 目標編集画面のエラー | 保存を拒否 |
| 一時停止からの復帰時にリソース不足 | モーダル | 遷移を拒否 |
| 教材の締切を過ぎても未完了 | ダッシュボードのバナー | 表示のみ |
| AI基盤が利用不可 | ダッシュボードのバナー | 表示のみ。記録機能は継続 |
| プロンプトの縮退が発生 | 対話領域の補足表示 | 表示のみ |

## 動作環境

- Windows PC（配布パッケージは Windows 向けの単一実行ファイル形式です）
- 主要モダンブラウザの最新版（Chrome / Edge 等）
- **インターネット接続は不要**（AI連携機能を使う場合のみ通信します）
- 学習データは端末内に保存され、外部のサーバーへは送信されません

## インストールと起動

1. GitHub Releases から `Michinari-v1.0.0.zip` をダウンロードします
2. 任意のフォルダに展開します（`Michinari` フォルダが作成されます）
3. フォルダ内の **`Michinari.bat`** をダブルクリックします
4. 自動的にブラウザが起動し、`http://127.0.0.1:8100` でアプリが表示されます
   （自動で開かない場合は同じURLへ手動でアクセスしてください）

起動したままウィンドウを閉じずにご使用ください。終了するときは、起動時に開いたコンソール
ウィンドウを閉じてください。

## データの保存場所

学習データは端末ごとに以下へ保存されます。

    %LOCALAPPDATA%\Michinari\data\
    ├── michinari.db     学習データ本体
    ├── backups\         バックアップ（アップデート時の自動退避を含む）
    └── exports\         エクスポートしたファイルの出力先

アプリを削除する場合は、展開したフォルダを削除してください。学習データも消す場合は
`%LOCALAPPDATA%\Michinari` を削除します（削除前に「データ管理」画面からのエクスポートを推奨します）。

## ご利用にあたっての注意

1. **AI機能の利用にはPATの設定が必要です。** 配布パッケージにはPATを同梱していません。
   設定しなくても記録・閲覧などの基本機能はご利用いただけます
2. **日次報告を確定すると内容は変更できません。** 確定前に内容をご確認ください
3. **データはお使いの端末にのみ保存されます。** 端末の入れ替え時は「データ管理」画面から
   エクスポートし、新しい端末でインポートしてください

## 開発者向けの補足

- 構成: バックエンド Python 3.12 / FastAPI / SQLAlchemy 2.0 / Alembic、
  フロントエンド TypeScript / Vite / React 19 / Tailwind 4、データストア SQLite
- 配布: PyInstaller による単一実行ファイル化 + zip、GitHub Releases 経由
- DBスキーマは起動時に自動マイグレーションされ、更新前にバックアップを自動作成します
- 画面文言はロケールファイル、閾値は `app_setting`、プロンプト文面は `prompt_template` へ
  外部化しています。フロントエンドのAPI型は `openapi-typescript` で自動生成しています
- エクスポートのスキーマ版数: ナレッジ `1.0`、全データ `1.0`
- 検証: バックエンド 637テスト／フロントエンド 115テスト
