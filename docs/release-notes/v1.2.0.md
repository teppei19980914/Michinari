# Michinari v1.2.0 リリースノート

公開日: 2026-09-11
前バージョン: v1.1.0（2026-09-11 公開）

読書の記録のしかたを見直しました。**「今日は何ページ読んだか」を思い出す必要がなくなり、「今どこまで読んだか」だけを入力すれば済みます。**

**主な変更**
- 読書の日次報告のページ入力を「現在ページ」1つだけに集約

- 現在ページが総ページ数を超えたときのエラー文言を具体化
- 読書のAIフィードバックへページの数値を渡さないよう修正

⚠️ **これまでの「読んだページ数」はアップデート時に削除されます（復元できません）。** 残す場合は事前にナレッジエクスポートで出力してください。総ページ数が未入力だった本には暫定値が入るため、アップデート後に「書籍」タブで正しい値へ直してください。

## このバージョンの概要

読書の記録のしかたを見直しました。**「今日は何ページ読んだか」を覚えておく必要がなくなり、「今どこまで読んだか」だけを入力すれば済むようになります。**

| | v1.1.0 | v1.2.0 |
| --- | --- | --- |
| 読書の日次報告のページ入力 | 「読んだページ数」と「現在ページ」の2つ | **「現在ページ」の1つだけ** |
| 書籍登録の総ページ数 | 任意（未入力可） | **必須** |
| ページ進捗の表示 | 総ページ数を入れた本のみ | **すべての本で表示** |
| 進捗率の上限 | なし | **100%** |
| AIへ渡すページの情報 | 読んだページ数・現在ページ | **渡さない** |

---

## 1. 読書の日次報告：入力が「現在ページ」だけになりました

これまでは「読んだページ数」と「現在ページ」の2つを入力する欄がありました。
v1.2.0 では **「現在ページ」の1つだけ** になります。

### なぜ変えたのか

「今日は何ページ読んだか」は、本を閉じたあとに思い出そうとしても分からない数字でした。
一方で「今どこまで読んだか」は、本を閉じた瞬間に目の前にある情報です。**思い出さなくても書ける値だけを聞く** 形に改めました。

読書は「1日○ページ読まないと間に合わない」というノルマ管理をしない目標です（v1.1.0 の設計方針）。そのため「その日に何ページ進んだか」という数字を残しておく必要がそもそもありませんでした。

### ご注意

**これまでに入力した「読んだページ数」は、アップデート時に削除されます。** 元に戻すことはできません。記録として残しておきたい場合は、アップデート前にナレッジエクスポートで出力してください。

なお「現在ページ」の入力は **これまでどおり任意** です。書かなくても報告を確定できます。

---

## 2. 書籍の登録：総ページ数が必須になりました

書籍を登録するとき、**総ページ数の入力が必須** になりました。

これにより、すべての読書目標でページ進捗（現在ページ ÷ 総ページ数）が表示されるようになります。これまでは総ページ数を入れていない本では進捗が一切表示されませんでした。

### 総ページ数はあとから直せます

登録時に入力した総ページ数が間違っていた場合、**現在ページより小さい値に訂正することもできます**。

たとえば「300ページ」として登録し250ページまで読んだあとで、実際は200ページだったと気づいた場合でも、200に直せます。確定済みの日次報告は変更できないため、先に現在ページを直すことができず訂正できなくなってしまう、という事態を避けるためです。

---

## 3. 進捗率は100%が上限になりました

ページ進捗が **100%を超えて表示されることはなくなりました**。

上記のように総ページ数をあとから小さく訂正した場合、一時的に「現在ページが総ページ数を上回る」状態になりますが、進捗の表示は100%で止まります。

---

## 4. 改善：入力ミスの理由が画面でわかるようになりました

現在ページに総ページ数を超える値を入力して報告しようとすると、これまでは「入力内容に誤りがあります」としか表示されませんでした。

v1.2.0 では **「現在ページは書籍の総ページ数以下で入力してください」** と、どこをどう直せばよいかが表示されます。

---

## 5. 変更：読書のAIフィードバックにページの数値を渡さなくなりました

読書の日次報告でAIと対話するとき、これまでは裏側で「読んだページ数」「現在ページ」がAIへ送られていました。

v1.2.0 では **ページに関する数値を一切送りません**。

### なぜ変えたのか

読書の日次報告は、進み具合を評価する場ではなく、**その日に感じたこと・考えたことを引き出す場** として設計されています。AIへの指示文にも「ページ数や読了ペースを評価しないでください」と明記していました。

にもかかわらず数値を渡していたため、指示と実際の動作が食い違っていました。今回これを解消しています。

**現在ページは、画面で進み具合を確認するためだけに使われます。**

## 7. その他の表示の変更

「読んだページ数」の廃止にともない、次の画面・出力から同項目が消えます。

- 日次報告の閲覧画面
- 分析画面の「読書記録」タブ
- ナレッジエクスポート（Markdown・JSON の両方）

いずれも「現在ページ」は引き続き表示・出力されます。

## アップデート時のご注意

1. **データは自動で移行されます。** アプリの起動時にデータベースが更新されます。過去の想起記録（今日読んだ内容の本文）はそのまま残ります

2. **「読んだページ数」は削除されます。** 復元はできません。残しておきたい場合はアップデート前にナレッジエクスポートで出力してください

3. **総ページ数が未入力だった本には、暫定の数値が自動で入ります。** その本で記録済みの「現在ページ」のうち最も大きい値（記録が1件もない場合は 1）が入ります。総ページ数はアプリが正しく推測できる値ではないため、**アップデート後に「書籍」タブで正しいページ数に直してください**

4. **v1.2.0 より前に出力した「全データのエクスポート」JSONは取り込めません。** データ構造が変わったためです。アップデートの前後でバックアップを取り直してください（データベースファイルの複製によるバックアップは、復元後に自動で移行されます）
