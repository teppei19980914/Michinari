### 8.1 責務分割の原則

| 層 | 責務 | 禁止事項 |
| --- | --- | --- |
| api | リクエスト受付、スキーマ検証、サービス呼び出し | 業務ロジックの記述 |
| services | 業務ロジック、算出、状態遷移の検証 | HTTPに関する知識 |
| models | データ構造の定義 | 業務ロジックの記述 |
| ai | AI基盤との通信、プロンプト組み立て、会話管理 | 業務判断 |

### 8.2 定数管理の原則

| 対象 | 配置先 |
| --- | --- |
| UI文言 | frontend/src/locales/ja.json |
| 列挙型の値 | backend/app/constants/、frontend/src/constants/ |
| 閾値およびパラメータ | app_setting テーブル（画面から変更可能） |
| プロンプト文面 | prompt_template テーブル（画面から変更可能） |

ソースコード中に文字列リテラルおよび数値リテラルを直接記述しない。
