### 5.6 インデックス定義

| テーブル | インデックス | 目的 |
| --- | --- | --- |
| daily_record | record_date（UNIQUE） | 日付検索 |
| study_log | (material_id, daily_record_id)（UNIQUE） | 重複防止、教材別集計 |
| study_log | (material_id, cycle_number) | 周回別の速度・品質算出 |
| study_log | daily_record_id | 日次記録からの取得 |
| chat_message | (daily_record_id, sequence) | 対話履歴の順序取得 |
| record_comment | daily_record_id | コメント一覧 |
| material | goal_id | 目標配下の教材取得 |
| material | due_date | 締切超過判定 |
| exam_subject | goal_id | 目標配下の科目取得 |
| material_subject | subject_id | 科目からの逆引き |
| load_profile | (goal_id, date_from, date_to) | 期間検索 |
| plan_baseline | (material_id, effective_from) | 有効基準の取得 |
| weekly_summary | (goal_id, week_start_date)（UNIQUE） | 生成済み判定 |
| goal_retrospective | (goal_id, generated_at) | 最新版の取得 |
| goal_retrospective | (goal_id, period_type, period_key, is_anonymized)（UNIQUE） | WORK月次報告・半期評価の期間別取得（EXAM／READINGではperiod_type・period_keyが共にNULLの行同士で一意性を保つ） |
| ai_conversation | (goal_id, scope, scope_key)（UNIQUE） | 会話識別子の取得 |
| book | goal_id（UNIQUE） | 1目標1冊の保証、目標からの逆引き |
| reading_log | (book_id, daily_record_id)（UNIQUE） | 重複防止、書籍別の想起記録取得 |
| reading_log | daily_record_id | 日次記録からの取得 |
| work_assignment | goal_id（UNIQUE） | 1目標1案件の保証、目標からの逆引き |
| work_log | (work_assignment_id, daily_record_id)（UNIQUE） | 重複防止、案件別の業務記録取得 |
| work_log | daily_record_id | 日次記録からの取得 |
| work_member | work_assignment_id | 案件別のメンバー一覧取得 |
| work_evaluation_report | member_id | メンバー別の評価レポート履歴取得 |
| calendar_day_override | target_date（PK） | 日種別解決 |
| holiday | holiday_date（PK） | 日種別解決 |
| ai_log | created_at | 保持期間による削除 |
