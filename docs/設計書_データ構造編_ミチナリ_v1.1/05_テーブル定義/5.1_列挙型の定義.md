### 5.1 列挙型の定義

アプリケーション層で Enum として定義し、データベースには文字列として保存する。

| 型名 | 値 | 意味 |
| --- | --- | --- |
| GoalStatus | DRAFT | 下書き |
| | ACTIVE | 進行中 |
| | PAUSED | 一時停止 |
| | CLOSED_WITH_RESULT | クローズ（受験結果あり） |
| | CLOSED_WITHOUT_RESULT | クローズ（中断・辞退） |
| ExamDateType | RANGE | 期間（暫定） |
| | FIXED | 確定日 |
| PassingScoreType | PERCENTAGE | 合格点を百分率（0〜100）で入力 |
| | RAW_SCORE | 合格点を素点／満点で入力 |
| DayType | PLAN | 計画日 |
| | BUFFER | バッファ日 |
| | OFF | 除外日 |
| Environment | ANY | 制約なし |
| | PC | 机上のみ |
| | MOBILE | 移動中でも可 |
| QualityMetricType | NONE | 記録しない |
| | OBJECTIVE | 客観正答率 |
| | SELF_SCORED | 自己採点得点率 |
| | SUBJECTIVE | 主観的手応え（5段階） |
| RecordState | PROGRESS_ONLY | 進捗のみ登録済 |
| | REPORTED | 報告済 |
| ChatRole | USER | 利用者の発言 |
| | ASSISTANT | AIの応答 |
| BaselineReason | INITIAL | 初回設定 |
| | REPLAN | リプラン実施 |
| | EXAM_DATE_FIXED | 受験日確定 |
| | MATERIAL_CHANGED | 教材構成の変更 |
| | CYCLE_CHANGED | 予定周回数の変更 |
| ExamResultType | PASS | 合格 |
| | FAIL | 不合格 |
| | PENDING | 未判定 |
| AiPurpose | DAILY_FEEDBACK | 日次報告フィードバック |
| | WEEKLY_SUMMARY | 週次要約生成 |
| | DAILY_MESSAGE | 今日の一言生成 |
| | GOAL_RETROSPECTIVE | 総括レポート生成 |
| | DAILY_FEEDBACK_READING | 読書日次報告フィードバック生成 |
| | GOAL_RETROSPECTIVE_READING | 読了レポート生成 |
| | DAILY_FEEDBACK_WORK | 仕事日次報告フィードバック生成 |
| | GOAL_RETROSPECTIVE_WORK_MONTHLY | 月次報告ドラフト生成 |
| | GOAL_RETROSPECTIVE_WORK_SEMIANNUAL | 半期評価レポート生成 |
| | EVALUATION_REPORT_WORK | AI評価レポート生成（要件定義書R-96、2026-09-23） |
| ConversationScope | DAILY_FEEDBACK | 日次報告の会話 |
| | WEEKLY_SUMMARY | 週次要約の会話 |
| | DAILY_MESSAGE | 今日の一言の会話 |
| | GOAL_RETROSPECTIVE | 総括レポートの会話 |
| | DAILY_FEEDBACK_READING | 読書日次報告の会話 |
| | GOAL_RETROSPECTIVE_READING | 読了レポートの会話 |
| | DAILY_FEEDBACK_WORK | 仕事日次報告の会話 |
| | GOAL_RETROSPECTIVE_WORK_MONTHLY | 月次報告の会話 |
| | GOAL_RETROSPECTIVE_WORK_SEMIANNUAL | 半期評価の会話 |
| | EVALUATION_REPORT_WORK | AI評価レポートの会話（メンバー単位、scope_key=member_id） |
| WorkMemberGender | MALE | 男性 |
| | FEMALE | 女性 |
| | OTHER | その他 |
| WorkEvaluationRole | EVALUATOR | 評価者（要件定義書R-95） |
| | EVALUATEE | 被評価者 |
| ExportFormat | MARKDOWN | 人間可読形式 |
| | JSON | 機械可読形式 |
| GoalCategory | EXAM | 資格試験（管理型：日次ノルマ・実効速度・リソース配分で計画を管理） |
| | READING | 読書（記録・活用型：想起の蓄積と読了レポートの生成が中心。日次ノルマ等は持たない） |
| | WORK | 仕事（記録・活用型の副分類「定期報告型」：日々の業務記録の蓄積と、月次・半期という周期での報告生成が中心。日次ノルマ等は持たない） |
| RetrospectivePeriodType | MONTHLY | 月次報告（goal_retrospective.period_type、WORKのみ使用） |
| | SEMI_ANNUAL | 半期評価（goal_retrospective.period_type、WORKのみ使用） |
