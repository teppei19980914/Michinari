## 2. 記号定義

| 記号 | 意味 |
| --- | --- |
| `T` | 論理的な本日（1日の境界時刻を考慮したシステム日付） |
| `m` | 教材（material） |
| `g` | 目標（goal） |
| `d` | 日付 |
| `A(m)` | 教材 m の1周分の総量（total_amount） |
| `N(m)` | 教材 m の予定周回数（planned_cycles） |
| `TW(m)` | 教材 m の総作業量 ＝ `A(m) × N(m)` |
| `C(m)` | 教材 m の累積完了量（全周回の合計） |
| `R(m)` | 教材 m の残量 |
| `k(m)` | 教材 m の現在周回 |
| `D(m)` | 教材 m の締切（due_date） |
| `S(m)` | 教材 m の開始日（start_date） |
| `type(d)` | 日 d の日種別（PLAN / BUFFER / OFF） |
| `w(g, d)` | 目標 g における日 d の負荷係数 |
| `P(m)` | 教材 m の残計画日集合 |
| `H(g, d)` | 目標 g が日 d に確保できる時間（時間単位） |
