### 17.5 総括レポート（GOAL_RETROSPECTIVE）

**注入する変数**

| 変数名 | 内容 |
| --- | --- |
| `{{goal_summary}}` | 試験名、学習期間、科目構成 |
| `{{material_summary}}` | 教材ごとの総量、予定周回、実績周回、投下時間 |
| `{{overall_metrics}}` | 総投下時間、学習日数、報告率、バッファ消費率、リプラン回数 |
| `{{quality_trend}}` | 品質指標の推移（周回別、月次集約） |
| `{{replan_history}}` | リプラン履歴（日付、契機、変更前後のノルマ、その時点の残量と残日数） |
| `{{weekly_summaries}}` | 週次要約が既に生成済みの範囲（`goal.start_date`〜生成時点）の圧縮表現 |
| `{{recent_logs}}` | 週次要約がまだ無い直近日の実績・日記（生ログ、S07 G6で新設） |
| `{{exam_results}}` | 科目ごとの合否と得点 |
| `{{anonymize}}` | 匿名化の指示（匿名化版生成時のみ） |

縮退段階は`{{weekly_summaries}}`→`{{recent_logs}}`の順（`prompt_builder.build_with_degradable_entries`、各段階とも古い記録〈リスト先頭〉から除外し、ある段階が尽きるまで次の段階へ進まない）。両方を使い切ってもなお超える場合は末尾を切り詰めるフェイルセーフに入る。

S07（G6）以前は`{{weekly_summaries}}`が対象期間を問わず全週の要約を返す専用関数
（`build_all_weekly_summaries_entries`）を使っており、週次要約がまだ無い直近日の実績・
日記を送る変数が無かった（読書の読了レポートには`{{reading_logs}}`として既にあった）。
`ai_context_common.resolve_weekly_compressed_period`（`period_start=goal.start_date`、
`period_end`=生成時点）で圧縮範囲を求め、`{{recent_logs}}`として
`ai_context_exam.build_recent_study_entries`（DAILY_FEEDBACKのS04 G2で新設済み）を
`exclude_covered_dates`で重複除去したうえで注入するよう改め、読書の読了レポートと同じ
方式に揃えた（CLAUDE.md DRYの原則）。

# このレポートの目的

このレポートには二つの読み手がいます。

1. 学習者本人（次回の受験、または別の試験に向けた振り返り）
2. 同じ試験を目指す他の学習者（経験の横展開）

したがって、**再現可能な知見**として記述してください。
「頑張った」「大変だった」といった感想ではなく、
**何を、どれだけ、どのように行った結果どうなったか**を
事実に基づいて述べてください。

---

# レポートの構成

## 1. 学習の全体像
期間、総投下時間、教材構成、周回数を簡潔にまとめてください。
数値を明示してください。

## 2. 計画と実績の乖離
当初の計画がどの程度実行されたかを述べてください。
計画の修正履歴を参照し、以下を分析してください。

- いつ、何回、どのような理由で計画を修正したか
- 修正のタイミングは適切だったか、遅すぎなかったか
- 修正が必要になった根本原因は何か
  （初期見積もりの甘さ、外部要因、実行力の問題のいずれか）

**この分析が本レポートの中核です。**
計画がいつ崩れ、いつ修正されたかという情報は、
通常の学習記録には残りません。丁寧に分析してください。

## 3. 品質の推移
品質指標がどのように推移したかを述べてください。
周回ごとの変化、停滞した時期、その時期に何が起きていたかを
週次要約と突き合わせて分析してください。

## 4. 結果の要因分析

### 合格していた場合
何が有効だったかを特定してください。
同じ試験を目指す人が再現すべき要素を、具体的に挙げてください。
時間配分、教材の選択、周回の進め方、修正の判断など、
再現可能な形で記述してください。

同時に、**運が良かっただけの要素**があれば
それも指摘してください。再現性のない成功要因を
一般化することは害になります。

### 不合格だった場合
何が不足していたかを特定してください。
学習者を責めるのではなく、構造的な要因を分析してください。

以下の観点で検討してください。
- 初期の総量見積もりは妥当だったか
- 確保できる時間に対して計画は現実的だったか
- 計画の修正が遅れた時点はあったか
- 品質指標の停滞を放置した期間はあったか
- 教材の選択や周回の進め方に問題はなかったか
- 学習時間の「形」（連続時間の確保）は適切だったか

そのうえで、**具体的に何をすべきだったか**を述べてください。
「もっと勉強すべきだった」ではなく、
「9月中旬の時点で必要速度が実効速度の1.5倍に達していたため、
この時点で受験日を後期に変更すべきだった」のように、
時点と根拠を伴う形で記述してください。

## 5. 次に向けた提言
学習者が次に同じ試験、または類似の試験に挑む際の
具体的な提言を、三点以内で述べてください。

- 合格を美化せず、不合格を過度に否定的に扱わないでください
- 他の学習者が読むことを前提に、
  この学習者固有の事情に依存しない知見を優先してください
