### 17.12 仕事用週次要約（WEEKLY_SUMMARY_WORK）

L-11（2026-09-15合意）で新設。17.11（読書用週次要約）と同じ理由・同じ設計（既存`weekly_summary`テーブルを共用）で、仕事にも週次要約層を設ける。

**注入する変数**

| 変数名 | 内容 |
| --- | --- |
| `{{week_range}}` | 対象週の期間 |
| `{{work_name}}` | 案件名（目標名） |
| `{{week_logs}}` | 週内の業務記録 |
| `{{anonymize}}` | 匿名化の指示（匿名化版生成時のみ） |

仕事も読書と同じ理由（業務記録body 1本のみで実績と所感が分かれていない、17.8参照）により、`{{week_recalls}}`（17.11）と同じ考え方で`{{week_logs}}`1本に統合する。

**初期文面**

```
以下は、仕事における一週間分の業務記録です。
この記録を、後日の振り返りに使えるよう要約してください。

# 対象週
{{week_range}}

# 案件
{{work_name}}

# 業務記録
{{week_logs}}

---

# 要約の要件

この要約は、後日の日次報告フィードバック・月次報告・半期評価の
生成時に「過去の経過」として参照されます。原文は参照されないため、
**この要約に含まれない情報は失われる**ことに留意してください。

以下を必ず含めてください。

1. この週に取り組んだ業務内容（時系列またはテーマ別）
2. 工夫や粘り強さが記述されている場合はその内容
   （成果の評価ではなく、プロセスの記録として）
3. 業務の妨げとなった要因（記録に現れたもの）
4. 前週からの変化

以下は含めないでください。
- ノルマの達成度や生産性の評価
- 励ましや評価のコメント
- 今後の提案

これは記録であり、フィードバックではありません。
事実と記録された内容に限定してください。

{{anonymize}}

# 出力形式
簡潔な文章で記述してください。
情報の欠落を避けることを最優先とし、
文章の美しさは考慮しなくて構いません。
```

匿名化版の生成時、`{{anonymize}}` に以下を差し込む（17.9・17.10の匿名化制約と同じ方針）。

```
# 追加の制約（匿名化）
業務内容、勤務先、家庭の事情、健康状態など、
個人を特定しうる情報および私的な事情への言及を
一切含めないでください。
```
