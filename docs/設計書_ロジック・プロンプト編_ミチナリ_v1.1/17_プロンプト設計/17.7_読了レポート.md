### 17.7 読了レポート（GOAL_RETROSPECTIVE_READING）

**注入する変数**

| 変数名 | 内容 |
| --- | --- |
| `{{book_summary}}` | 書名、著者、読書期間（開始日〜読了日） |
| `{{overall_metrics}}` | 記録日数、最長連続記録日数 |
| `{{weekly_summaries}}` | 既に週次要約が生成済みの範囲の圧縮表現（21.4「圧縮境界の解決」、L-11） |
| `{{reading_logs}}` | 週次要約がまだ及んでいない直近部分の想起記録を record_date の昇順で連結したもの（21.4参照） |
| `{{anonymize}}` | 匿名化の指示（匿名化版生成時のみ） |

**初期文面**

```
以下は、ある読者が1冊の本を読み進める中で書き残した
想起の記録です。この記録をもとに、読了レポートを
作成してください。

# 書籍
{{book_summary}}

# 記録量
{{overall_metrics}}

# これまでの経過（週次要約）
{{weekly_summaries}}

# 直近の想起記録
{{reading_logs}}

---

# このレポートの目的

このレポートには複数の使い方があります。

1. 読者本人による読了後の振り返り
2. ブログ記事など、他者に向けた発信の下敷き
3. 他者にこの本を紹介する際の資料

したがって、記録に書かれていた事実（読者が実際に何を
感じ、何を考えたか）を丁寧に拾いながら、単なる記録の
時系列列挙ではなく、まとまりのある文章として構成して
ください。

---

# レポートの構成

## 1. 本の要約
書籍の内容を、記録から読み取れる範囲で簡潔に要約して
ください。記録に現れていない一般的な書評的知識で
補わないでください。

## 2. 感じたこと・考えたこと
記録全体を通じて読者がどのような感情や考えを持ったかを、
具体的な記述を引用しながらまとめてください。
読書の途中で考えが変化した箇所があれば、その変化を
時系列で示してください。

## 3. 気づき
記録の中で読者自身が「気づいた」「初めて分かった」と
記述している内容、またはそれに相当する記述を抽出し、
まとめてください。

## 4. 印象に残った部分
記録の中で特に多く言及されている、あるいは強い感情を
伴って書かれている箇所を挙げてください。

---

# 記述上の注意

- 記録に現れていない内容を推測で補わないでください
- 読者を評価したり、読み方を批評したりしないでください
- 他者が読むことを想定し、この読者固有の事情に依存しない
  範囲で、本の魅力が伝わる記述を心がけてください

{{anonymize}}

# 出力形式
見出しを用いた構造的な文書として記述してください。
分量の制約はありません。
```

匿名化版の生成時、`{{anonymize}}` に以下を差し込む。

```
# 追加の制約（匿名化）
業務内容、勤務先、家庭の事情、健康状態など、
個人を特定しうる情報および私的な事情への言及を
一切含めないでください。
```
