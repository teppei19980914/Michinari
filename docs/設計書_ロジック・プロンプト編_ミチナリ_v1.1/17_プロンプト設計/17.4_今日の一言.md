### 17.4 今日の一言（DAILY_MESSAGE）

複数目標が同時進行している場合、このプロンプトは**目標ごとに独立して**呼び出す（1呼び出し=1目標、他目標の情報は一切渡さない）。順調な目標の情報に引っ張られて、停滞している目標の実態と乖離した一言が生成されることを構造的に防ぐため（未決事項L-04）。ACTIVEな目標が1件も無い日のみ、`{{goal_summary}}`等が「進行中の目標はありません」となる状態で1回呼び出す。テンプレート本文・変数自体は変更しない。

**AI未設定時（S-4 4-1、2026-09-20）**：AI呼び出し自体を行わない（本プロンプトは呼び出されない）。`daily_message_service.get_or_generate`はAI認証状態を先に確認し、未設定ならフロントのロケールファイルへ外部化した固定のねぎらい文言をDBへ保存せずそのまま返す。AI設定後の再取得で通常のプロンプト呼び出しへ自動的に切り替わる。

**注入する変数**

| 変数名 | 内容 |
| --- | --- |
| `{{today}}` | 論理的な本日の日付 |
| `{{day_type}}` | 本日の日種別 |
| `{{goal_summary}}` | 目標名と残日数 |
| `{{progress_summary}}` | 教材ごとの進捗率と現在周回 |
| `{{recent_activity}}` | 直近7日間の報告状況と実績 |

**初期文面**

```
学習者がアプリケーションを起動した際に表示する、
短い一言を生成してください。

# 状況
日付：{{today}}
日種別：{{day_type}}

# 目標
{{goal_summary}}

# 進捗
{{progress_summary}}

# 直近の活動
{{recent_activity}}

---

# 要件

- **一文から二文**。長くしないでください
- 前向きな内容にしてください
- 進捗の具体的な事実に触れてください。
  抽象的な励ましは避けてください
- 遅れている場合でも、責める表現は用いないでください。
  事実に触れつつ、前を向ける表現にしてください
- バッファ日の場合、休息を肯定する内容も適切です
- 周回が切り替わった直後であれば、その節目に触れても
  構いません
- 毎日表示されるため、定型的な表現の繰り返しを避けてください

# 例（形式の参考）
「過去問道場が2周目に入りました。1周目より速く進んでいます」
「3日ぶりですね。今日は30分だけでも進めれば流れが戻ります」
「今日はバッファ日です。休むことも計画のうちです」

# 出力形式
一言のみを出力してください。前置きや説明は不要です。
```

**要約・縮退の原則（R-35）の対象外（S08 G8、2026-10-20合意）**：本プロンプトは、R-35「過去の報告内容は週次要約として保持し、対話時の入力に用いること。全期間の原文を入力に含めないこと」の対象外とする。`{{recent_activity}}`は直近7日固定の軽量な集計であり、全期間を漏れなく入力する設計要求を持たない（R-36「進捗状況を踏まえた肯定的な短文」、1〜2文の短文生成が目的）。対象に含める場合、`weekly_summary_service`相当の仕組みを新設し`{{weekly_summaries}}`を読み込む必要があるが、短文生成に対して不釣り合いなコスト（文字数・読み込み）になるため採用しない。
