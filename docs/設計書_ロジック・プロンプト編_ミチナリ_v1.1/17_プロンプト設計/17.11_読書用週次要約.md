### 17.11 読書用週次要約（WEEKLY_SUMMARY_READING）

L-11（2026-09-15合意）で新設。日次報告フィードバック（21.4）・読了レポート（21.4）で「古い日から削る」段階的縮退が対象期間の前半の情報を失わせる副作用を持つため、根本対応として、読書にも資格試験（17.3）と同じ「週次要約による圧縮」層を設ける。既存の`weekly_summary`テーブル（goal_id単位の汎用スキーマ）をそのまま共用し、スキーマ変更は不要（データ構造編5.5）。

**注入する変数**

| 変数名 | 内容 |
| --- | --- |
| `{{week_range}}` | 対象週の期間 |
| `{{book_title}}` | 書名 |
| `{{week_recalls}}` | 週内の想起記録 |
| `{{week_chat}}` | 週内のAIとの対話（DAILY_FEEDBACK_READING）のうち、利用者本人の発言（role=USER）のみ（S08 G5、17.3と同じ方針） |
| `{{anonymize}}` | 匿名化の指示（匿名化版生成時のみ） |

読書は資格試験と異なり、実績（学習量）と日記（所感）が分かれておらず、想起記録（recall_body）1本に両方の性質を持つ（17.6参照）。そのため`{{week_logs}}`・`{{week_diaries}}`・`{{week_metrics}}`に相当する3変数の分割は行わず、`{{week_recalls}}`1本に統合する。`{{week_chat}}`はG5（2026-10-20合意）で追加（詳細は17.3参照）。

**初期文面**

```
以下は、読書における一週間分の想起記録です。
この記録を、後日の振り返りに使えるよう要約してください。

# 対象週
{{week_range}}

# 書籍
{{book_title}}

# 想起記録
{{week_recalls}}

# 本人の発言（AIとの対話）
{{week_chat}}

---

# 要約の要件

この要約は、後日の日次報告フィードバック・読了レポートの
生成時に「過去の経過」として参照されます。原文は参照されないため、
**この要約に含まれない情報は失われる**ことに留意してください。

以下を必ず含めてください。

1. この週に読んだ内容として記録された事実
2. 感じたこと・考えたこと（読者が用いた表現や
   説明の粒度を保存してください。想起記録に加え、
   AIとの対話中の発言も対象とします）
3. 気づき（「気づいた」「初めて分かった」に相当する記述）
4. 前週からの考えの変化（記録に現れた場合）

以下は含めないでください。
- ページ数や読了ペースに関する評価
- 励ましや評価のコメント
- 今後の提案

これは記録であり、フィードバックではありません。
事実と記録された感想に限定してください。

{{anonymize}}

# 出力形式
簡潔な文章で記述してください。
情報の欠落を避けることを最優先とし、
文章の美しさは考慮しなくて構いません。
```

匿名化版の生成時、`{{anonymize}}` に以下を差し込む（17.7の匿名化制約と同じ方針）。

```
# 追加の制約（匿名化）
書名以外の、個人を特定しうる情報および
私的な事情への言及を一切含めないでください。
```
