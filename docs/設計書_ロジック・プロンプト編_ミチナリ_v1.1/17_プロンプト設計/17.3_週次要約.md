### 17.3 週次要約（WEEKLY_SUMMARY）

**注入する変数**

| 変数名 | 内容 |
| --- | --- |
| `{{week_range}}` | 対象週の期間 |
| `{{goal_name}}` | 目標名 |
| `{{week_logs}}` | 週内の日別実績（周回を含む） |
| `{{week_diaries}}` | 週内の日記（行動・所感、学んだこと） |
| `{{week_metrics}}` | 週の集計値（総投下時間、総完了量、品質指標の平均、報告日数、バッファ消費） |
| `{{anonymize}}` | 匿名化の指示（匿名化版生成時のみ） |

**初期文面**

```
以下は、資格試験の学習における一週間分の記録です。
この記録を、後日の振り返りに使えるよう要約してください。

# 対象週
{{week_range}}

# 目標
{{goal_name}}

# 実績
{{week_logs}}

# 集計
{{week_metrics}}

# 日々の記録
{{week_diaries}}

---

# 要約の要件

この要約は、後日のフィードバック生成時に「過去の経過」として
参照されます。原文は参照されないため、**この要約に含まれない
情報は失われる**ことに留意してください。

以下を必ず含めてください。

1. 学習量と品質の推移（数値を含む）
2. この週に学習した主題と、その理解度に関する記述
   （後日の比較対象となるため、学習者が用いた表現や
     説明の粒度を保存してください）
3. 学習の妨げとなった要因（業務、体調、家庭の事情など、
   記録に現れたもの）
4. 学習者の状態に関する所見（意欲、疲労度、余裕の有無）
5. 前週からの変化
6. 教材の周回が進んだ場合、その事実と切り替えの時期

以下は含めないでください。
- 励ましや評価のコメント
- 今後の提案

これは記録であり、フィードバックではありません。
事実と観察に限定してください。

{{anonymize}}

# 出力形式
簡潔な文章で記述してください。
情報の欠落を避けることを最優先とし、
文章の美しさは考慮しなくて構いません。
```

匿名化版の生成時、`{{anonymize}}` に以下を差し込む。

```
# 追加の制約（匿名化）
業務内容、勤務先、家庭の事情、健康状態など、
個人を特定しうる情報および私的な事情への言及を
一切含めないでください。
学習の妨げとなった要因については、
「業務多忙」「体調不良」といった一般化された表現に
留めてください。
```
