## 5. 負荷係数の解決

### 5.1 解決規則

```
w(g, d) = load_profile のうち、goal_id = g かつ
          date_from ≤ d ≤ date_to を満たすレコードの coefficient
          
          該当するレコードが存在しない場合は 1.0
```

`load_profile` は同一目標内で期間が重複しないよう制約されているため、該当レコードは0件または1件となる。

### 5.2 検証規則

負荷プロファイルの登録・更新時に以下を検証する。

| 検証項目 | 条件 |
| --- | --- |
| 期間の妥当性 | `date_from ≤ date_to` |
| 係数の妥当性 | `coefficient > 0` |
| 期間の重複 | 同一 goal 内の既存レコードと期間が重複しないこと |
